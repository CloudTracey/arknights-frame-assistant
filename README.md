## 下载及启用方法

1. 从 [GitHub Releases 页面](https://github.com/CloudTracey/arknights-frame-assistant/releases) 或者[AFA官方下载源（仅中国大陆可用）](https://release.arknightsframeassistant.com/latest)下载最新版本的 exe 文件
2. 与游戏一同启动（没有先后顺序要求），或在设置中开启自动启动选项
3. 对所希望修改的按键和设置进行自定义
4. 点击**保存并关闭**或**应用设置**，即可在游戏中生效

<br>

## 功能特性

AFA 的设置窗口分为「常规作战」「快捷操作」「卫戍协议」「自定义按键」「特殊操作」「其他设置」六个页面，各页面的主要功能与设置如下。

### 过帧与精细操作

以下为「常规作战」页面可用的按键功能与相关设置：

| 功能 | 说明 |
|------|------|
| 按下时暂停 | 按下时切换暂停 |
| 松开时暂停 | 松开时切换暂停，还原模拟器“点击”的手感 |
| 切换倍速 | 切换游戏倍速（1 倍/2 倍） |
| 暂停时选中 | 暂停时，鼠标移动到想选中的单位上，点击选中 |
| 技能 | 点击技能键 |
| 撤退 | 点击撤退键 |
| 视角切换 | 暂停时，鼠标移动到单位上，点击后即可将摄像头中心切换到该单位上 |
| 前进 16ms | 暂停时使用，游戏时间向前推进 16ms |
| 前进 33ms | 暂停时使用，游戏时间向前推进 33ms |
| 前进 166ms | 暂停时使用，游戏时间向前推进 166ms |
| 一键技能 | 鼠标移动到想要开技能的单位上，按下后自动选中并开启技能 |
| 一键撤退 | 鼠标移动到想要撤退的单位上，按下后自动选中并撤退 |
| 暂停技能 | 暂停时，鼠标移动到想要开技能的单位上，按下后自动选中并开启技能 |
| 暂停撤退 | 暂停时，鼠标移动到想要撤退的单位上，按下后自动选中并撤退 |
| 游戏内帧率 | 按游戏实际运行帧数选择档位（30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+），保证过帧延迟计算准确 |
| 仅在关卡内启用常规作战热键（实验性） | 识别关卡界面，在关卡界面外禁用常规作战热键，避免误触发 |

- 三档“前进”的实际等待时长可在「其他设置 → 自定义」中调整，调整后热键名称与状态栏提示会同步变化

### 快捷操作

| 功能 | 说明 |
|------|------|
| 模拟左键点击 | 模拟按下鼠标左键 |
| 基建快速收取 | 点击屏幕左下角的基建收取按钮收取产物 |
| 放弃行动 | 放弃当前作战 |
| 跳过招募动画/剧情 | 快速移动鼠标点击右上角的跳过按钮 |
| 肉鸽收取道具 | 快速移动鼠标点击集成战略的“收下”按钮 |
| 返回上级菜单 | 模拟点击 ESC 键，返回上一级菜单 |
| 使用“返回上级菜单”放弃行动 | 使“返回上级菜单”按下 ESC 的同时按下“放弃行动”键 |

### 卫戍协议操作

| 功能 | 说明 |
|------|------|
| 查看敌人 | 查看敌人信息 |
| 调度中心 | 打开调度中心（商店） |
| 冻结 | 冻结调度中心（商店） |
| 刷新 | 刷新调度中心（商店） |
| 准备就绪 | 确认准备就绪 |
| 模拟左键点击 | 模拟按下鼠标左键 |
| 升级 | 升级调度中心（商店） |
| 出售/销毁 | 出售干员/销毁装备 |
| 单位撤退 | 撤退选中单位 |
| 一键撤退 | 点击鼠标位置单位后自动撤退 |
| 一键出售/销毁 | 点击鼠标位置干员/装备后自动出售/销毁 |
| 一键购买 | 模拟双击左键，购买调度中心商店中的单位 |

> **注意**：卫戍协议方案与常规作战、快捷操作方案互斥：切换到「卫戍协议」页面时，常规作战与快捷操作按键将被禁用；切换到「常规作战」或「快捷操作」页面时，卫戍协议按键将被禁用

### 全按键自定义

所有按键功能均可在设置窗口中重新绑定，其中常规作战的常用功能预置了默认按键：

**常规作战默认按键：**

| 功能 | 默认按键 | 功能 | 默认按键 |
|------|----------|------|----------|
| 按下时暂停 | F | 前进 16ms | 无 |
| 松开时暂停 | Space | 前进 33ms | R |
| 切换倍速 | D | 前进 166ms | T |
| 暂停时选中 | W | 一键技能 | E |
| 技能 | S | 一键撤退 | Q |
| 撤退 | A | 暂停技能 | 鼠标前侧键 |
| 视角切换 | 无 | 暂停撤退 | 鼠标后侧键 |

- 支持绑定键盘上的绝大多数按键
- 支持绑定除鼠标左键外的鼠标按键（包括滚轮和侧键）
- 使用 `BACKSPACE/DELETE` 可清除绑定
- 修改按键时会实时检测冲突并标红相关输入框，存在冲突时需先解决后才能保存
- 设置窗口底部的「重置按键」可恢复除自定义按键外的全部按键设置为默认值

**自定义按键：**

「自定义按键」页最多可添加 12 个自定义按键：可设置按键名称、类型（全局按键 / 常规作战类 / 快捷操作类 / 卫戍协议类）与功能，点击游戏窗口即可直接获取希望执行操作的坐标，点击行末齿轮可随时编辑或删除。按键类型决定生效范围：

- 全局按键：始终生效
- 常规作战类：仅在作战关卡内生效
- 快捷操作类：在未启用卫戍协议方案时全局生效
- 卫戍协议类：仅在启用卫戍协议方案时生效

### 特殊操作

「特殊操作」页面集中放置开局阶段与游戏音量相关的功能：

| 功能 | 说明 |
|------|------|
| 开局自动暂停 | 进入关卡时自动按下暂停，可绑定「启用/禁用开局自动暂停」快捷键随时切换 |
| 按住开局暂停 | 在关卡加载时按住，进入关卡后会自动暂停（不受「启用开局自动暂停」勾选与否的影响） |
| 开局自动二倍速 | 进入关卡时自动切换到二倍速，可绑定「启用/禁用开局自动二倍速」快捷键随时切换 |
| 提高音量 | 提高游戏客户端在 Windows 音量合成器中的音量 |
| 降低音量 | 降低游戏客户端在 Windows 音量合成器中的音量 |
| 静音 | 切换游戏客户端的静音状态 |

> **提示**：「特殊操作」页的热键默认均未绑定，可在该页自行绑定；游戏音量控制的热键在任一功能页面均生效

## 注意事项

### 仅对明日方舟进程生效

本程序的按键功能仅对明日方舟进程（`Arknights.exe`）生效，不会影响游戏以外的操作

### 游戏内按键设置

AFA 会自动读取游戏内的按键设置并动态适配

如果自动读取失败，AFA 会弹出提示并回退使用默认按键。此时请**手动将游戏内按键恢复为默认设置**以保证功能正常

### 关于游戏内帧率

小助手内的"游戏内帧率"选项为 **30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+**，请选择与游戏实际运行帧数一致的档位，以保证过帧延迟计算准确

- 如果你的屏幕刷新率**大于等于 120 Hz**：可以开启垂直同步，帧率档位对应选择 120 或以上
- 如果你的屏幕刷新率**低于 120 Hz**：建议不要开启垂直同步，确保帧率设置与游戏中实际帧数一致；若开启垂直同步，则需确保该设置与显示器刷新率一致

### 安全提示

本程序基于 AutoHotkey 开发。大部分 MMORPG 或竞技类网游的反作弊系统对 AutoHotkey 开发的程序非常敏感，可能将其误判为作弊程序，导致游戏无法启动甚至账号封禁。

**强烈建议开启"随游戏进程关闭自动退出"功能**（默认开启），避免因忘记关闭本工具而触发其他游戏的反作弊机制。

### 如果不小心关闭了设置界面

未启用“关闭窗口时退出小助手”时，从电脑右下角托盘区（含隐藏图标）找到小助手图标，右键点击**打开设置界面**即可重新打开设置界面。若已启用该选项，点击 X 会退出程序，需要重新启动 AFA

## 常见问题

### Q: 程序启动后没有反应？

A: 请检查以下几点：
1. 确认程序以管理员权限运行
2. 确认游戏已经启动
3. 检查右下角托盘区是否有小助手图标（包括隐藏的托盘区图标）
4. 检查是否在设置里关闭了"启动时打开设置窗口"

### Q: 按键绑定后不生效？

A: 请检查：
1. AFA 是否弹出"游戏按键读取失败"提示（如有，请将游戏内按键恢复默认）
2. 修改后是否应用或保存设置
3. 按键是否与其他软件冲突
4. 是否在游戏窗口内操作

### Q: GitHub Token 是什么？需要配置吗？

A: GitHub Token 用于提高 API 请求配额。只有在提示 API 配额超限时才需要配置，一般情况下无需使用。

GitHub Token 会使用 Windows DPAPI 按当前 Windows 用户加密保存，不再以明文写入配置文件。首次启动新版时，旧版明文 Token 会自动迁移为加密格式；如果将配置文件复制到其他 Windows 用户或电脑，通常需要重新输入 Token。

### Q: 如何彻底退出小助手？

A: 可以右键点击托盘区图标选择“退出”，也可以在“启动与退出”设置中开启**关闭窗口时退出小助手**，之后点击设置窗口右上角 X 或按 Alt+F4 退出。如果开启了**随游戏进程关闭自动退出**，游戏退出后 AFA 也会随之一同退出。

### Q: 如何收集日志反馈问题？

A: 打开设置中的“日志”页面，点击**生成日志压缩包**，将生成的 ZIP 文件随 Issue 或反馈一同提供。日志默认保存在 `%AppData%\ArknightsFrameAssistant\PC\logs`
