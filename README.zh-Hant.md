## 下載及啟用方法

1. 從 [GitHub Releases 頁面](https://github.com/CloudTracey/arknights-frame-assistant/releases)，或 [AFA 官方下載源（僅中國大陸可用）](https://release.arknightsframeassistant.com/latest) 下載最新版本的 exe 檔案
2. 與遊戲一同啟動（沒有先後順序要求），或在設定中開啟自動啟動選項
3. 對所希望修改的按鍵和設定進行自定義
4. 點擊**儲存並關閉**或**套用設定**，即可在遊戲中生效

## 功能特性

AFA 的設定視窗分為「常規作戰」「快捷操作」「衛戍協議」「自訂按鍵」「特殊操作」「其他設定」六個頁面，各頁面的主要功能與設定如下。

### 過幀與精細操作

以下為「常規作戰」頁面可用的按鍵功能與相關設定：

| 功能 | 說明 |
|------|------|
| 按下時暫停 | 按下時切換暫停 |
| 放開時暫停 | 鬆開時切換暫停，還原模擬器「點擊」的手感 |
| 切換倍速 | 切換遊戲倍速（1倍/2倍） |
| 暫停時選取 | 暫停時，滑鼠移動到想選取的單位上，點擊選取 |
| 技能 | 點擊技能鍵 |
| 撤退 | 點擊撤退鍵 |
| 視角切換 | 暫停時，滑鼠移動到單位上，點擊後即可將攝影機中心切換到該單位上 |
| 前進 16ms | 暫停時使用，遊戲時間向前推進 16ms |
| 前進 33ms | 暫停時使用，遊戲時間向前推進 33ms |
| 前進 166ms | 暫停時使用，遊戲時間向前推進 166ms |
| 一鍵技能 | 滑鼠移動到想要開技能的單位上，按下後自動選取並開啟技能 |
| 一鍵撤退 | 滑鼠移動到想要撤退的單位上，按下後自動選取並撤退 |
| 暫停技能 | 暫停時，滑鼠移動到想要開技能的單位上，按下後自動選取並開啟技能 |
| 暫停撤退 | 暫停時，滑鼠移動到想要撤退的單位上，按下後自動選取並撤退 |
| 遊戲內幀率 | 依遊戲實際執行幀數選擇檔位（30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+），保證過幀延遲計算準確 |
| 僅在關卡內啟用常規作戰熱鍵（實驗性） | 識別關卡介面，在關卡介面外停用常規作戰熱鍵，避免誤觸發 |

- 三檔「前進」的實際等待時長可在「其他設定 → 自訂」中調整，調整後熱鍵名稱與狀態列提示會同步變化

### 快捷操作

| 功能 | 說明 |
|------|------|
| 模擬左鍵點擊 | 模擬按下滑鼠左鍵 |
| 基建快速收取 | 點擊螢幕左下角的基建收取按鈕收取產物 |
| 放棄行動 | 放棄目前作戰 |
| 跳過招募動畫/劇情 | 快速移動滑鼠點擊右上角的跳過按鈕 |
| 肉鴿收取道具 | 快速移動滑鼠點擊整合戰略的「收下」按鈕 |
| 返回上級選單 | 模擬點擊 ESC 鍵，返回上一級選單 |
| 使用「返回上級選單」放棄行動 | 使「返回上級選單」按下 ESC 的同時按下「放棄行動」鍵 |

### 衛戍協議操作

| 功能 | 說明 |
|------|------|
| 查看敵人 | 查看敵人資訊 |
| 調度中心 | 開啟調度中心（商店） |
| 凍結 | 凍結調度中心（商店） |
| 重新整理 | 刷新調度中心（商店） |
| 準備就緒 | 確認準備就緒 |
| 模擬左鍵點擊 | 模擬按下滑鼠左鍵 |
| 升級 | 升級調度中心（商店） |
| 出售/銷毀 | 出售幹員/銷毀裝備 |
| 單位撤退 | 撤退選取單位 |
| 一鍵撤退 | 點擊滑鼠位置單位後自動撤退 |
| 一鍵出售/銷毀 | 點擊滑鼠位置幹員/裝備後自動出售/銷毀 |

> **注意**：衛戍協議方案與常規作戰、快捷操作方案互斥：切換到「衛戍協議」頁面時，常規作戰與快捷操作按鍵將被停用；切換到「常規作戰」或「快捷操作」頁面時，衛戍協議按鍵將被停用

### 全按鍵自定義

所有按鍵功能均可在設定視窗中重新綁定，其中只有常規作戰的部分常用功能預設了預設按鍵：

**常規作戰預設按鍵：**

| 功能 | 預設按鍵 | 功能 | 預設按鍵 |
|------|----------|------|----------|
| 按下時暫停 | F | 前進 16ms | 無 |
| 放開時暫停 | Space | 前進 33ms | R |
| 切換倍速 | D | 前進 166ms | T |
| 暫停時選取 | W | 一鍵技能 | E |
| 技能 | S | 一鍵撤退 | Q |
| 撤退 | A | 暫停技能 | 滑鼠前側鍵 |
| 視角切換 | 無 | 暫停撤退 | 滑鼠後側鍵 |

- 支援綁定鍵盤上的絕大多數按鍵
- 支援綁定除滑鼠左鍵外的滑鼠按鍵（包括滾輪和側鍵）
- 使用 `BACKSPACE/DELETE` 可清除綁定
- 修改按鍵時會即時偵測衝突並標紅相關輸入框，存在衝突時需先解決後才能儲存
- 設定視窗底部的「重設按鍵」可恢復除自訂按鍵外的全部按鍵設定為預設值

**自訂按鍵：**

「自訂按鍵」頁面最多可新增 12 個自訂按鍵：可設定按鍵名稱、類型（全域按鍵 / 常規作戰類 / 快捷操作類 / 衛戍協議類）與功能，點擊遊戲視窗即可直接取得希望執行操作的座標，點擊行末齒輪可隨時編輯或刪除。按鍵類型決定生效範圍：

- 全域按鍵：始終生效
- 常規作戰類：僅在作戰關卡內生效
- 快捷操作類：在未啟用衛戍協議方案時全域生效
- 衛戍協議類：僅在啟用衛戍協議方案時生效

### 特殊操作

「特殊操作」頁面集中放置開局階段與遊戲音量相關的功能：

| 功能 | 說明 |
|------|------|
| 開局自動暫停 | 進入關卡時自動按下暫停，可綁定「啟用/停用開局自動暫停」快捷鍵隨時切換 |
| 按住開局自動暫停 | 在關卡載入時按住，進入關卡後會自動暫停（不受「啟用開局自動暫停」勾選與否的影響） |
| 開局自動二倍速 | 進入關卡時自動切換到二倍速，可綁定「啟用/停用開局自動二倍速」快捷鍵隨時切換 |
| 提高音量 | 提高遊戲用戶端在 Windows 音量混音器中的音量 |
| 降低音量 | 降低遊戲用戶端在 Windows 音量混音器中的音量 |
| 靜音 | 切換遊戲用戶端的靜音狀態 |

> **提示**：「特殊操作」頁的熱鍵預設均未綁定，可在該頁自行綁定；遊戲音量控制的熱鍵在任一功能頁面均生效

## 注意事項

### 僅對明日方舟進程生效

本程式的按鍵功能僅對明日方舟進程（`Arknights.exe`）生效，不會影響遊戲以外的操作

### 遊戲內按鍵設定

AFA 會自動讀取遊戲內的按鍵設定並動態適配

如果自動讀取失敗，AFA 會彈出提示並回退使用預設按鍵。此時請**手動將遊戲內按鍵恢復為預設設定**以保證功能正常

### 關於遊戲內幀率

小助手內的「遊戲內幀率」選項為 **30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+**，請選擇與遊戲實際執行幀數一致的檔位，以保證過幀延遲計算準確

- 如果你的螢幕更新率**大於等於 120 Hz**：可以開啟垂直同步，幀率檔位對應選擇 120 或以上
- 如果你的螢幕更新率**低於 120 Hz**：建議不要開啟垂直同步，確保幀率設定與遊戲中實際幀數一致；若開啟垂直同步，則需確保該設定與顯示器更新率一致

### 安全提示

本程式基於 AutoHotkey 開發。大部分 MMORPG 或競技類線上遊戲的反作弊系統對 AutoHotkey 開發的程式非常敏感，可能將其誤判為作弊程式，導致遊戲無法啟動甚至帳號封鎖。

**強烈建議開啟「隨遊戲進程關閉自動退出」功能**（預設開啟），避免因忘記關閉本工具而觸發其他遊戲的反作弊機制。

### 如果不小心關閉了設定介面

未啟用「關閉視窗時退出小助手」時，從電腦右下角系統匣（含隱藏圖示）找到小助手圖示，右鍵點擊**開啟設定介面**即可重新開啟設定介面。若已啟用該選項，點擊 X 會退出程式，需要重新啟動 AFA

## 常見問題

### Q: 程式啟動後沒有反應？

A: 請檢查以下幾點：
1. 確認程式以系統管理員權限執行
2. 確認遊戲已經啟動
3. 檢查右下角系統匣是否有小助手圖示（包括隱藏的系統匣圖示）
4. 檢查是否在設定裡關閉了「啟動時開啟設定視窗」

### Q: 按鍵綁定後不生效？

A: 請檢查：
1. AFA 是否彈出「遊戲按鍵讀取失敗」提示（如有，請將遊戲內按鍵恢復預設）
2. 修改後是否套用或儲存設定
3. 按鍵是否與其他軟體衝突
4. 是否在遊戲視窗內操作

### Q: GitHub Token 是什麼？需要設定嗎？

A: GitHub Token 用於提高 API 請求配額。只有在提示 API 配額超限時才需要設定，一般情況下無需使用。

GitHub Token 會使用 Windows DPAPI 按目前 Windows 使用者加密儲存，不再以明文寫入設定檔。首次啟動新版時，舊版明文 Token 會自動遷移為加密格式；如果將設定檔複製到其他 Windows 使用者或電腦，通常需要重新輸入 Token。

### Q: 如何徹底退出小助手？

A: 可以右鍵點擊系統匣圖示選擇「退出」，也可以在「啟動與退出」設定中開啟**關閉視窗時退出小助手**，之後點擊設定視窗右上角 X 或按 Alt+F4 退出。如果開啟了**隨遊戲進程關閉自動退出**，遊戲退出後 AFA 也會隨之一同退出。

### Q: 如何收集日誌回報問題？

A: 開啟設定中的「日誌」頁面，點擊**產生日誌壓縮包**，將產生的 ZIP 檔案隨 Issue 或回報一同提供。日誌預設儲存在 `%AppData%\ArknightsFrameAssistant\PC\logs`
