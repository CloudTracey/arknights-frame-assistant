## 下載及啟用方法

1. 從 [GitHub Releases 頁面](https://github.com/CloudTracey/arknights-frame-assistant/releases) 下載最新版本的 exe 檔案
2. 與遊戲一同啟動（沒有先後順序要求），或在設定中開啟自動啟動選項
3. 對所希望修改的按鍵和設定進行自定義
4. 點擊**儲存並關閉**或**應用設定**，即可在遊戲中生效

## 注意事項

### 僅對明日方舟進程生效

本程式的按鍵功能僅對明日方舟進程（`Arknights.exe`）生效，不會影響遊戲以外的操作。

### 遊戲內按鍵設定

AFA 會自動讀取遊戲內的按鍵設定並動態適配

如果自動讀取失敗，AFA 會彈出提示並回退使用以下預設按鍵。此時請**手動將遊戲內按鍵恢復為預設設定**以保證功能正常：

**常規作戰：**
- 戰鬥內變速：F
- 釋放技能：E
- 撤退幹員：Q
- 放棄行動：V
- 暫停：空白鍵

**衛戍協議：**
- 查看敵人：W
- 調度中心：A
- 凍結：S
- 重新整理：D
- 準備就緒：C
- 升級：G
- 出售：X

### 關於遊戲內幀率

小助手內的「遊戲內幀率」選項為 **30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+**，請選擇與遊戲實際執行幀數一致的檔位，以保證過幀延遲計算準確。

- 如果你的螢幕更新率**大於等於 120 Hz**：可以開啟垂直同步，幀率檔位對應選擇 120 或以上
- 如果你的螢幕更新率**低於 120 Hz**：建議不要開啟垂直同步，確保幀率設定與遊戲中實際幀數一致；若開啟垂直同步，則需確保該設定與顯示器更新率一致

### 安全提示

本程式基於 AutoHotkey 開發。大部分 MMORPG 或競技類線上遊戲的反作弊系統對 AutoHotkey 開發的程式非常敏感，可能將其誤判為作弊程式，導致遊戲無法啟動甚至帳號封鎖。

**強烈建議開啟「隨遊戲進程關閉自動退出」功能**（預設開啟），避免因忘記關閉本工具而觸發其他遊戲的反作弊機制。

開啟「隨明日方舟自動啟動小助手」後，Windows 會透過安全日誌中的進程建立事件識別 `Arknights.exe`，並使用帶目前使用者 SID 的計畫任務啟動小助手。關閉該功能時會刪除目前使用者的計畫任務，但 Windows 的「進程建立成功審核」設定會保留，並可能增加安全日誌記錄量。

兩個自動啟動方向可以同時開啟：小助手啟動遊戲時不會重複啟動小助手，遊戲啟動小助手時也不會重複啟動遊戲。

### 如果不小心關閉了設定介面

未啟用「關閉視窗時退出小助手」時，從電腦右下角系統匣（含隱藏圖示）找到小助手圖示，右鍵點擊**開啟設定介面**即可重新開啟設定介面。若已啟用該選項，點擊 X 會退出程式，需要重新啟動 AFA。

## 常見問題

### Q: 程式啟動後沒有反應？

A: 請檢查以下幾點：
1. 確認程式以系統管理員權限執行
2. 確認遊戲已經啟動
3. 檢查右下角系統匣是否有小助手圖示（包括隱藏的系統匣圖示）
4. 檢查是否在設定裡關閉了「啟動時開啟設定視窗」

### Q: 按鍵綁定後不生效？

A: 請檢查：
1. AFA 是否彈出「遊戲按鍵讀取失敗」提示（如有，請將遊戲內按鍵恢復預設）
2. 修改後是否套用或儲存設定
3. 按鍵是否與其他軟體衝突
4. 是否在遊戲視窗內操作

### Q: GitHub Token 是什麼？需要設定嗎？

A: GitHub Token 用於提高 API 請求配額。只有在提示 API 配額超限時才需要設定，一般情況下無需使用。

GitHub Token 會使用 Windows DPAPI 按目前 Windows 使用者加密儲存，不再以明文寫入設定檔。首次啟動新版時，舊版明文 Token 會自動遷移為加密格式；如果將設定檔複製到其他 Windows 使用者或電腦，通常需要重新輸入 Token。

### Q: 如何徹底退出小助手？

A: 可以右鍵點擊系統匣圖示選擇「退出」，也可以在「啟動與退出」設定中開啟**關閉視窗時退出小助手**，之後點擊設定視窗右上角 X 或按 Alt+F4 退出。如果開啟了**隨遊戲進程關閉自動退出**，遊戲退出後 AFA 也會隨之一同退出。

### Q: 如何收集日誌回報問題？

A: 開啟設定中的「日誌」頁面，點擊**產生日誌壓縮包**，將產生的 ZIP 檔案隨 Issue 或回報一同提供。日誌預設儲存在 `%AppData%\ArknightsFrameAssistant\PC\logs`，一般日誌與關鍵錯誤上下文分軌滾動，合計容量上限為 20 MiB；匯出包會過濾 Token、使用者目錄和其他敏感資訊。

## 介面主題

在 **其他 → 顯示 → 介面主題** 中選擇「跟隨系統」「淺色」「深色」或「自訂主題」。預設跟隨 Windows 的應用程式主題，系統主題變更時自動切換，無需重新啟動。

選擇後立即預覽；儲存或套用後記住，取消時還原已儲存的主題。設定、按鍵編輯、公告及更新等應用程式視窗會同步套用；系統檔案選擇器、系統匣選單和除錯主控台維持原樣。開啟高對比度時優先使用系統配色。

選擇「自訂主題 → 編輯自訂主題」，可用取色器或 `#RRGGBB` 編輯視窗背景、控制項背景、主要文字和強調色。僅儲存一套方案；還原淺色或深色配色不會清除圖片。對比度不足時提示但仍可儲存。

支援本機 PNG、JPG/JPEG、BMP（最多20 MiB、1600萬像素），可選填滿裁切／完整顯示及0–100%圖片不透明度（預設20%）。圖片僅在自訂模式的主設定視窗顯示；輸入框、按鈕維持實色背景，其他對話框不鋪圖。儲存時複製到 `%AppData%\ArknightsFrameAssistant\PC\backgrounds`，移動原圖不影響已儲存背景；內部副本遺失時退回純色。

編輯器使用系統配色。「完成編輯」只接受預覽，仍需回主視窗儲存或套用；編輯器取消還原開啟前的方案，主視窗取消還原已儲存方案。切換其他主題時隱藏圖片但保留自訂方案。
