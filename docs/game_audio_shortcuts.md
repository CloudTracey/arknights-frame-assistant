# 游戏音频快捷键

在「快捷操作」中设置一键静音、提高游戏音量、降低游戏音量。新配置默认 F8、Ctrl+↑、Ctrl+↓；已有 F3 等自定义绑定继续使用。保存或应用后生效，沿用快捷操作的生效条件与方案切换。

每次增减 10 个百分点，限制为 0%–100%，可以按住连续调节。提高音量时，每个会话必须先成功写入音量，才能解除其静音；降低音量保持静音状态，0% 不额外设置静音。

仅修改目标明日方舟进程在活动输出设备上的音频会话，不修改系统总音量及其他程序。优先读取默认多媒体输出上的活动游戏会话，其次其他活动会话、未过期会话；按计算出的目标同步现有会话。单个失效会话不阻断其他会话，部分失败会显示提示。

热键回调只提交动作与当时的窗口句柄，定时器验证进程身份后执行 COM 操作；最多四个排队动作共用一次快照，按顺序逐次计算和限制音量，空闲时没有音频巡检。COM 接口在快照结束时统一释放。

相邻、同一进程、同方向的待执行音量输入合并，增减方向或静音操作之间不合并。队列达到 16 项后，不能合并的新音量输入不再接受；已接受动作仍按顺序执行，静音操作继续接受。超载时不保证每次音量输入均被执行。
静音切换时，若部分状态读失败且其余可读会话都已静音，则保持原状态并报告失败；不会根据未知状态解除静音。已确认有未静音会话时，仍可静音其他可用会话。

本变更只包含手动操作：无会话时提示未找到，不保存待执行音量；切换设备或创建新会话后，需要再次按键。后台自动静音及退出恢复、设备通知及音量保持分开提交，避免在首份 PR 中混入原生模块和恢复状态机。退出 AFA 不回滚用户设置的音量或手动静音。

验证范围为 Windows 11 x64。静态检查和冒烟测试不代表真实游戏、GUI 或设备验收；人工验证见 `test/test_audio_shortcuts.md`。
