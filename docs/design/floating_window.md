# 悬浮窗

## 创建与显示

`FloatingWindow` 只在首次显示时创建一个 Gui，显示/隐藏复用该对象。设置提交或语言切换时，先隐藏并保存尺寸，再重建内容。

`WantVisible` 表示请求状态，`IsVisible` 表示已经完成的显示状态。`Changing` 串行化创建与重建；期间收到的显示/隐藏请求在当前操作完成后统一执行。新 Gui 及其控件在创建成功后才发布到类字段。

## 透明度

沿用仓库内 AHK 官方文档 `docs/ahk_docs/lib/Gui.htm#ExOSD` 的 OSD 模式：普通 Gui 添加控件后，将 Gui 对象直接传入窗口透明度函数，再显示窗口。鼠标穿透通过 `WinSetExStyle("+0x20", guiObj)` 开启。

隐藏窗口必须用 Gui 对象或纯整数 HWND 定位。`"ahk_id " hwnd` 仍是窗口搜索字符串，受隐藏窗口检测设置影响，不能等同于纯 HWND。

不手动预置 WS_EX_LAYERED、不调用 SetLayeredWindowAttributes、不强制重绘、不注册 Size 回调。

## 尺寸与交互

持久化宽高统一为 AHK Gui 逻辑像素。读取使用 `Gui.GetClientPos`，首次创建使用 `Gui.Show`。屏幕坐标和鼠标位移为物理像素；鼠标位移除以 `A_ScreenDPI / 96` 后参与尺寸计算。调整窗口时使用 `WinMove`，仅将逻辑宽高乘回 DPI 比例，X/Y 保持屏幕物理坐标。

AHK v2.0.26 的 `source/script_gui.cpp` 中 `GuiType::Move` 会缩放 X/Y/W/H 四个参数，与本地 Gui.Move 文档仅缩放宽高的说明不同，因此不使用 Gui.Move 定位。每次显示前检查显示器工作区，回收移出屏幕的窗口。

右键热键只启动一个 16 ms 定时器。每次回调最多进行一次几何更新；几何未改变时不操作窗口。松开右键、隐藏或正常退出时经 SettingsService 保存尺寸。任务栏、菜单和按键录制期间不截获右键。

日志记录创建、显示、隐藏、快捷键注册和尺寸保存，便于区分绘制问题与状态问题。

列宽、文字高度通过 Text 控件首次自动定尺寸后的 GetPos 测量。字体使用 Metrics.FontFor 按当前语言选择。最小宽度为最长功能名列、最长按键列、列间距与两侧边距之和；最小高度为所有实测行高、行间距与上下边距之和。按键列使用实际测量宽度，功能名列吸收放大时的额外空间。

边距、列间距、最小行高、字号、拖动命中区域及刷新间隔是 FloatingWindow 中的命名设计参数。DPI 基准 96 和 WS_EX_TRANSPARENT 值属于平台约定；不作为内容尺寸的限制。配置默认值与尺寸上限集中在 Constants，3000×2000 逻辑像素是现有最大尺寸限制，正常内容最小尺寸优先于该限制。

文字颜色根据配置背景的相对亮度，从黑/白中选择对比度更高的一种。计算公式采用 [WCAG 对比度及相对亮度定义](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，该选择针对配置背景色，不表示半透明合成后的画面满足某一对比度等级。

托盘通过唯一的“显示/隐藏悬浮窗”项切换状态，显示时打勾。勾选状态只根据完成后的 IsVisible 更新，托盘重建后重新同步。

## 当前方案

悬浮窗通过 HotkeyService.GetEnabledBindingIds 获取当前已启用方案的内置/自定义绑定标识，不自行维护另一套方案状态。HotkeyGroupChanged、HotkeyStateChanged 触发内容刷新。常规作战/快捷操作与卫戍协议互斥，自定义按键采用 HotkeyService.CustomProfiles 中已验证的生效组；全局自定义按键在两种方案中均显示。

热键总开关关闭时隐藏游戏及自定义动作；SwitchHotkey 和悬浮窗切换键独立于该开关，仍显示已绑定项。

实际方案组变化时，窗口高度按当前显示行的实测高度、行间距和上下边距重新计算，不继承前一方案保存的高度。常规作战与快捷操作属于同一方案组，二者之间切页不触发高度重置。悬浮窗尚未创建时先记录适配请求，首次显示时再按当前内容计算高度。

游戏热键菜单项按当前名称重命名，不依赖菜单序号。设置页的按键录制通过 Config.AllHotkeys（来自 Schema）、SwitchHotkey 和自定义按键控件模式识别，普通输入框无需逐个加入排除清单。

“显示”页面分为两栏：左栏为原显示设置和顶部标签页管理，右栏为独立的悬浮窗设置、操作说明及特性。文本按列宽自动换行；底部按钮基准取基础功能提示与显示设置控件底部的最大值，避免翻译变长后覆盖按钮。
