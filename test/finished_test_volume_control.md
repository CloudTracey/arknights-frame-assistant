# 测试清单：`test_volume_control`

> 对应更改：新增 AFA 游戏音量控制——修改 Windows 音量合成器中的游戏应用音量，多设备同步、500ms 轮询、外部修改取消同步、三个音量热键、特殊操作页 GUI 与 ToolTip 反馈。

## 测试环境

| 项目 | 信息 |
|------|------|
| AFA 版本 | `v2.2.0` |
| AutoHotkey 版本 | `v2.0.26`（项目推荐版本；若实际运行版本不同请修正） |
| Windows 版本 | `Windows 10.0.26300.9711`（由 `cmd /c ver` 读取；若实际版本不同请修正） |
| 测试日期 | `2026-11-06` |

### 测试前提

- AFA 以管理员权限运行；游戏正常启动，音频处于共享模式（非独占）。
- 至少一个输出设备能听到游戏声音；多设备项需要两个及以上活动输出设备。
- 多开项需要两个明日方舟实例；ToolTip 项建议在窗口化/无边框模式下观察（独占全屏可能看不到原生 ToolTip）。
- 能把 AFA 设置窗口和 Windows 音量合成器并排操作；能手动修改「明日方舟」的应用音量/静音。
- 测试中不要同时修改多个变量；先记录当前音量值，便于判断 10% 步进。

### 问题2：三个音量热键均提示「游戏音量：控制失败」，音量无变化
- [x] 已解决
- 记录日期：2026-11-06
- 复现步骤：游戏在前台且正在输出声音；按「提高音量」「降低音量」或「静音」任意一个。
- 实际现象：ToolTip 显示「游戏音量：控制失败」；Windows 音量合成器中「明日方舟」的应用音量与静音状态均无变化。
- 期望行为：按清单第 5 组、第 6 组正常步进 10%、静音/取消静音。
- 日志证据（`%AppData%\ArknightsFrameAssistant\PC\logs\afa-*.log`）：
  - `[WARN] [VolumeController] 枚举音频会话失败：This local variable has not been assigned a value. A global declaration inside the function may be required.`
  - `[INFO] [HotkeyActions] 音量操作：reason=failed volume=0 muted=否 成功会话=0/0`
- 根因（Lead 确认）：`VolumeController._IidBuffer()` 内 `buffer := Buffer(16, 0)` 的局部变量名与 AHK 内建 `Buffer` 类同名；AHK 把右侧 `Buffer` 解析为尚未赋值的同名局部变量，抛出 UnsetError，导致每次 `_Scan` 在开始枚举设备会话前即失败。已重命名为 `guidBuf`，其余逻辑不变。
- 修复状态：已修复，第 5、6、7 组复测通过，已解决（2026-11-06）。
- 影响：第 5 组（单设备基本音量与 ToolTip）、第 6 组（双设备音量同步）不通过；第 7–12 组（新设备、外部修改、静音多设备、多开、生命周期、异常反馈）依赖成功写入，未能验证，需在修复后统一重测。

### 问题3：音量 ToolTip 首次触发与后续触发的位置、大小不一致
- [x] 已解决
- 记录日期：2026-11-06
- 现象：按音量键触发的 ToolTip，首次与后续显示的位置、尺寸不一致；2026-11-06 首次发现后仅偶发，游戏重启后再次出现且更明显：ToolTip 向左下角偏移、尺寸变大。怀疑与 DPI 有关但未确认（原记录为仅观察，不做分析）。

### 问题4：新音频会话在轮询前未同步，切换设备后可能短暂出声（优化点）
- [x] 已解决（按用户决定接受限制）
- 记录日期：2026-11-06
- 场景：已设置静音/音量后，把输出从外放扬声器切换到耳机，游戏在耳机上建立新的音频会话。
- 现象：新会话在 500ms 轮询前保持未同步状态；若此前已静音，游戏会在切换后的设备上先出声一小会，直到轮询把目标音量/静音应用到新会话。
- 修复（Lead，2026-11-06）：轮询间隔由 3000ms 调整为 500ms，新会话最多等下一轮 500ms。
- 方案决策（2026-11-06）：用户确认保持 500ms 轮询，接受切换瞬间的短暂出声；不引入 `IAudioSessionNotification` 自定义 COM 接收器，避免新增 vtable/回调生命周期风险。该行为记录为已知体验限制。
- 剩余风险：切换设备的瞬间仍可能听到极短声音；不视为功能失败。
- 影响：第 7 组（新设备插入与无会话设备）功能通过；本优化点按用户决定关闭。
