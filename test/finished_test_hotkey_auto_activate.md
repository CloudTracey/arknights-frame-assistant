# 测试清单：热键自动激活游戏窗口（#213 失焦操作）

> 对应更改：实现 issue #213"根据鼠标下方的顶层窗口判断是否触发某些热键"——游戏窗口失焦时，鼠标悬停在游戏窗口上即可触发热键（无需先获取窗口焦点）。改动两处：① `HotkeyContext` 键盘键判定改为"游戏为活动窗口 OR 鼠标悬停游戏窗口"（纯判定无副作用）；② `_RegisterOne` 对鼠标键/键盘键主热键与 OnUp 型动作回调统一包装（`_WrapAction`）：执行前 `WinActivate` 游戏 + `WinWaitActive`（超时 500ms 则跳过动作）；激活后**不恢复原窗口**（焦点留在游戏，由用户自行切换回）。守卫补发 Up 变体与 SwitchKey 切换键不包装。
