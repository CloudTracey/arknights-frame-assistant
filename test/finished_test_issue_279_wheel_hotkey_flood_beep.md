## 问题反馈

### 问题1：报告人"只有嘟嘟声"与警告路径的同源性未在实机确认（待 alpha 版报告人实测）

- [x] **本机复现取证**（复现脚本 v3：`A_MaxHotkeysPerInterval=10` / `A_HotkeyInterval=1000`，物理按键重复触发；v1/v2 发现 AHK v2 对注入事件一律不触发热键，洪泛计数从未发生）：
  - 阈值溢出 → AHK 警告**弹窗 + 播放系统提示音**（本机渲染为 Win11 通知音）；`A_HotkeyInterval := 0` 后**弹窗与声音均消失**。
  - 结论：警告路径本身确实"弹窗+声音"同源，且被 `=0` 完全封死。
- [ ] **未闭环**：报告人听到的是"嘟嘟"（与 Win11 通知音音色不同），同源性存在两种可能——(a) 同源：警告声音按报告人机器的声音方案/编码渲染为"嘟嘟"，弹窗被全屏游戏遮挡只闻其声；(b) 异源：嘟嘟来自游戏/鼠标驱动/系统其它机制，与 AHK 警告无关。
- [x] **处理**：维持 `A_HotkeyInterval := 0` 修复；发布包含本修复的 alpha 版，由报告人在其复现环境（无级滚轮 + 快速滚动）实测：嘟嘟消失=同源闭环；仍出现=异源，届时评估节流方案（对转发/非过帧类动作限频等）。
- [ ] 已解决（待报告人实测确认后勾选）
