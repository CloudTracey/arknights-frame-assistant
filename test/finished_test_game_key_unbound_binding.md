## 集成测试

### 流程：游戏内清空「出售」后的注入行为（核心修复）

> 涉及模块：`core/hotkey/game_keys.ahk`、`core/hotkey/hotkey_actions.ahk`、`core/hotkey/hotkey_service.ahk`

- [x] **前置**：AFA 已用源码启动并切到「卫戍协议」页；游戏已进入卫戍协议，场上至少一个干员，商店可见
- [x] **操作**：游戏内按键设置里把「刷新」改绑到 `X`（与「出售」默认键冲突），冲突确认框点确认 →「出售」被清空
- [x] **预期**：10 秒内日志出现 `[GameKeys] 检测到按键变更，发布 GameKeysChanged`，新映射行里 `autochessRefresh=x`、`autochessSale=(未绑定)`，其余功能不变
- [x] **预期**：紧跟一条 `[WARN] [GameKeys] 区服 CN 以下功能游戏内未绑定按键，AFA 不会为其注入按键：autochessSale`
- [x] **操作**：鼠标停在场上干员上，按 AFA 的「出售/销毁」热键
- [x] **预期**：**商店不刷新**、干员不出售（对比修复前：会刷新商店）
- [x] **预期**：日志出现一次 `[WARN] [GameKeys] 功能 autochessSale 在游戏内未绑定按键，跳过注入`
