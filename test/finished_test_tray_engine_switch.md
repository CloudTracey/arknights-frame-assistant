# 测试清单：`test_tray_engine_switch`

> 对应更改：托盘新增与当前引擎相反的切换项：web 模式显示「切换到经典界面(Windows原生GUI)」，经典模式显示「切换到现代界面(WebView2)」。点击后先确认「是否切换并重启」，确认后才写入 `UiEngine` 并立即重启；取消则完全不写配置。web 模式的入口不依赖网页是否可用；切到现代前若本机无 WebView2 Runtime，先弹与设置页相同的确认。
>
> **取代声明**：本清单取代 `test/finished_test_ui_engine_setting.md` 中「托盘菜单不再有引擎切换项」的预期；该文件其余内容仍为历史验收档案。
