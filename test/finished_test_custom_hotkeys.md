# 测试清单：`custom_hotkeys`

> 对应更改：新增「自定义按键」功能——新顶部标签页、最多 12 条自定义热键（按键绑定 + 命名 + 按键类型 + tap/usleep 指令脚本）、齿轮编辑窗口（含坐标拾取与帮助）、独立存储 `CustomHotkeys.json`、按类型并入既有热键组与冲突检测。

## 测试环境

| 项目 | 信息 |
|------|------|
| AFA 版本 | `v2.0.0-alpha.5` |
| AutoHotkey 版本 | `v2.0.26` |
| Windows 版本 | `Windows 11 25H2` |
| 测试日期 | `2026-08-23` |
