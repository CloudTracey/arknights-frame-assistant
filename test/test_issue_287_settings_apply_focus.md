## 单元测试

### 功能点：鼠标点击「应用设置」后的焦点

- [ ] **前置**：打开设置窗口 → 其他设置 → 自定义；修改任意设置（如「点击延迟」值）。
- [ ] **操作**：用鼠标点击「应用设置」按钮，待成功弹窗关闭。
- [ ] **预期**：焦点停在**「取消」按钮**，**不**跳到「点击延迟」输入框；输入框无选中/聚焦状态。

### 功能点：从 Edit 按 Enter 应用

- [ ] **前置**：同上，焦点在「点击延迟」或「过帧档位1」输入框中。
- [ ] **操作**：直接按 Enter（触发默认按钮「应用设置」）。
- [ ] **预期**：窗口行为正常（应用成功）；焦点保持在可预期位置，**不**出现意外跳转或闪烁；按 Enter 不产生按键录制/误触发。

### 功能点：重置路径（复用同一按钮状态逻辑）

- [ ] **操作**：在有修改且存在热键冲突时（模拟：将两个热键绑定为同键）点击「应用设置」。
- [ ] **预期**：按钮保持可用的冲突提示逻辑不变；修复只在按钮被禁用时才转移焦点，无冲突场景行为不变。

### 功能点：无修改时按钮禁用与 Tab 遍历

- [ ] **前置**：回到无修改状态。
- [ ] **操作**：确认「保存并关闭」「应用设置」为禁用态；用 Tab 遍历控件。
- [ ] **预期**：按钮禁用态正常；Tab 顺序与修复前一致（无跳序）。
