# 测试清单：`framerate_auto_detect`

> 对应更改：新增游戏内帧率「自动适配」模式（默认）——读取游戏注册表 `common_setting` 的 `fpsStrategy`/`enableVSync`，垂直同步开启时结合游戏窗口所在显示器刷新率计算实际帧率；保留原有手动档位（30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+），选中时仍按旧逻辑换算延迟。自动识别失败时回退 60fps。

## 集成测试

### 流程：自动适配 + VSync 关闭 → 按游戏内档位识别

> 涉及模块：`GameFrameRate`、`UnityPlayerPrefs`、`TimingService`

- [x] **前置**：下拉框选择「自动适配」；游戏内关闭垂直同步；打开调试日志控制台
- [x] **操作**：游戏内帧率设为 30，等 10~12 秒
- [x] **预期**：日志 `帧率识别：…垂直同步关闭，fpsStrategy=0，游戏帧率=30fps`；`时序缓存刷新：帧率来源=自动识别 30fps，CurrentDelay …→34`
- [x] **操作**：游戏内帧率改为 60，等 10~12 秒
- [x] **预期**：`fpsStrategy=1，游戏帧率=60fps`；`CurrentDelay …→17`
- [x] **操作**：游戏内帧率改为 120，等 10~12 秒
- [x] **预期**：`fpsStrategy=2，游戏帧率=120fps`；`CurrentDelay …→9`
- [x] **操作**：仅调节游戏音量并等待 10 秒
- [x] **预期**：不产生新的帧率识别日志（无关字段变化不触发重算）

### 流程：自动适配 + VSync 开启 → 按窗口所在显示器刷新率识别

> 涉及模块：`GameFrameRate`、`DisplayInfo`、`TimingService`

- [x] **前置**：游戏以无边框/窗口化模式运行；下拉框为「自动适配」；确认当前显示器刷新率
- [x] **操作**：游戏内开启垂直同步，等 10~12 秒
- [x] **预期**：日志 `…垂直同步开启，屏幕刷新率=<N>Hz，游戏帧率=<N>fps`（与 Windows 显示设置一致）；N≥120 时 `CurrentDelay …→9`
- [x] **操作**：在 Windows 显示设置中改刷新率（如 60Hz ↔ 120/165Hz），等 10~12 秒
- [x] **预期**：识别值跟随变化；`CurrentDelay` 在 17 / 9 间对应变化（独占全屏下改桌面刷新率可能不生效，可切窗口化再测）
- [x] **操作**：多显示器时，把游戏窗口拖到刷新率不同的另一块屏，等 10~12 秒
- [x] **预期**：识别跟随游戏窗口所在显示器而非主屏（两块屏刷新率相同时此项跳过）

### 流程：自动适配识别失败 → 回退 60fps

> 涉及模块：`GameFrameRate`、`TimingService`

- [x] **前置**：游戏内开启垂直同步；AFA 设置里关闭「随游戏进程关闭自动退出」；下拉框为「自动适配」
- [x] **操作**：关闭游戏，等 10~12 秒
- [x] **预期**：日志 `帧率识别暂不可用，回退 60fps：…原因=游戏窗口不存在…`（**INFO 级别**，普通日志可见；`logs/critical-*.log` 中不应出现）；`时序缓存刷新：帧率来源=自动适配未识别，回退 60fps，CurrentDelay …→17`；之后不重复刷同样日志
- [x] **操作**：重新启动游戏并等窗口出现，等 10~12 秒
- [x] **预期**：识别成功，`CurrentDelay` 恢复对应值
- [x] **操作**：完全退出游戏后先启动 AFA（VSync 仍开启），再启动游戏
- [x] **预期**：AFA 先出现一次「暂不可用」INFO 日志、无报错、`critical-*.log` 不被污染；游戏窗口出现后约 10 秒内识别成功

### 流程：手动档位模式 → 使用旧逻辑，不受自动识别影响

> 涉及模块：`TimingService`、`GameFrameRate`

- [x] **前置**：游戏内帧率 120、关闭垂直同步；打开调试日志控制台
- [x] **操作**：AFA 下拉框手动选择「60」并保存/应用
- [x] **预期**：`时序缓存刷新：帧率来源=手动档位 60，CurrentDelay …→17`；即使游戏帧率是 120，延迟也保持 17
- [x] **操作**：AFA 手动改选「120」并保存/应用
- [x] **预期**：`CurrentDelay …→9`
- [x] **操作**：手动选择「30」「90」「144」「165」「180」「240+」并依次观察日志
- [x] **预期**：`CurrentDelay` 分别为 34 / 12 / 8 / 7 / 6 / 5
- [x] **操作**：保持手动档位，游戏内把 VSync/帧率改来改去并等待
- [x] **预期**：AFA 的 `CurrentDelay` 不因自动识别结果变化（手动档位优先）

### 流程：自动适配 ↔ 手动档位切换

- [x] **操作**：从手动「60」切回「自动适配」并保存/应用（游戏内 120fps、VSync 关闭）
- [x] **预期**：`帧率来源=自动识别 120fps，CurrentDelay …→9`
- [x] **操作**：从「自动适配」切到手动「30」并保存/应用
- [x] **预期**：`帧率来源=手动档位 30，CurrentDelay …→34`，不会回退到自动值
- [x] **操作**：切换模式后点「取消」
- [x] **预期**：恢复为已保存的模式与延迟

### 流程：设置保存 / 应用 / 取消

- [x] **前置**：自动适配识别成功
- [x] **操作**：修改无关设置后「应用」，再「保存并关闭」；随后「取消」一次
- [x] **预期**：每次保存/应用后自动识别结果仍生效，不出现“回退 60fps”日志；取消后恢复已保存状态
