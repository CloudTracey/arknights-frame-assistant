- [x] **操作**：确认更新并进入自替换步骤，观察更新 cmd 窗口。
- [x] **预期**：更新 cmd 窗口内**只**显示批处理自身输出（Waiting for AFA to exit... / 替换相关文案），**不再出现** `[Shutdown] 程序退出 reason=...` 或任何 AFA 日志行。（本轮观察：更新窗口干净，直至替换完成仅批处理输出；详见取证）
- [x] **操作**：检查 AFA 旧进程是否自行退出、新版本是否启动。
- [x] **预期**：更新流程完整：替换成功 → 新版本启动 → 更新日志 `update-*.log` 完整记录。

### 流程：新版本调试控制台恢复
