## 单元测试

### 功能点：H1 随游戏自动启动的计划任务可见性

> 前置说明：计划任务曾被卡巴斯基误报时删除，且 AFA 仅在启动时（`Reconcile()`）重建任务。需先运行**新版 AFA**（含去 Hidden 改动）触发重建，再查看任务计划程序。
> ⚠️ **测试中发现的卡巴斯基环境问题**：卡巴斯基实时防护会在 AFA 注册任务后**删除任务文件**（`System32\Tasks` 无文件、schtasks 找不到、任务不触发），导致功能失效。**解决：卡巴斯基信任 AFA + 重启系统**后恢复正常。这不是代码问题（v1.6.0 旧版同样受影响）。

- [x] **前置**：确认 `AutoStartWithGame=1`、`GamePath` 已设置（当前配置已满足）
- [x] **操作**：运行 `E:\AFA\src\main.exe`（v1.8.0，含去 Hidden 改动的新版；编译入口 main.ahk 产物名为 main.exe）
- [x] **预期**：AFA 正常启动，日志记录"计划任务已注册"；卡巴斯基拦截在「信任 + 重启」后解决
- [x] **操作**：COM 查询任务状态（普通权限读不了 schtasks/任务文件，用 COM 验证）
- [x] **预期**：任务存在、`Hidden=False`（去 Hidden 生效）、`Enabled=True`、State=3 就绪
- [x] **操作**：查看任务"触发器"和"操作"
- [x] **预期**：触发器为事件订阅（Security 4688 进程创建事件），操作为启动 AFA（`--game-autostart` 参数）
- [x] **操作**：关闭 AFA → 启动游戏 → 验证自动拉起
- [x] **预期**：游戏启动自动拉起 AFA（用户确认正常；COM 记录 LastRun 14:56、LastResult 0x0 成功）
