## 回归测试

### 功能：主题切换的既有边界

- [x] 验证：**仅预览**主题（改下拉框但不保存）→ 不重建窗口、日志中不出现「热键已重建」
  - 说明：保存/应用主题**会**重建热键——`HotkeyService._HandleSettingsSavedOrApplied()`（`hotkey_service.ahk:164-169`）对任何保存/应用/重置都无条件 `EnableByTab()`，与是否改过热键、是否改过主题无关。原测试项表述有误（写成"切主题后不应出现热键重建"），已按实际行为修正。
- [x] 验证：五语言下「其他设置 → 显示」页的「界面主题」标签与下拉框不截断、不重叠

### 功能：保存/应用/取消的通用脏状态

- [x] 验证：改任意一项 → 按钮亮起 + 红字 → 点「取消」→ 修改丢弃、按钮变灰
