> 设置界面只捕获物理键，字母大小写会统一显示；这里不要求分别设置 `a` 和 `A`。

- [x] **前置**：通过设置界面将一个常规作战快捷键设置为 `A`，启用关卡检测守卫并应用设置。
- [x] **操作**：进入会触发“被关卡检测拦截”的小游戏，短按 A 10 次。
- [x] **预期**：每次松开后角色立即停止向左移动，不需要再次按 A 才恢复。
- [x] **操作**：按住 A 3 秒后松开，重复 5 次。
- [x] **预期**：按住期间角色持续向左，松开立即停止；每次保持只产生一组 `KeyForward` 透传 Down/Up 调试记录。

### 功能点：旧配置 A/a 错配专项回归

> 此项用于精确复现 Issue #240 的历史配置状态，需要直接编辑配置文件；日常 GUI 测试可先跳过。

- [x] **前置**：完全退出 AFA，备份 `%AppData%\ArknightsFrameAssistant\PC\Settings.ini`。
- [x] **操作**：在 `[Hotkeys]` 段将 `Retreat` 设置为 `A`，将互斥标签页中的 `DispatchCenter` 设置为 `a`，保存后重新启动 AFA；不要通过设置界面重新录制这两个键。
- [x] **预期**：AFA 正常载入配置；配置文件中保留本次测试所需的 `A/a` 拼写差异。
- [x] **操作**：进入小游戏，短按、长按并快速连按 A 各 10 次。
- [x] **预期**：每次 Up 都能匹配先前记录的 Down，角色松开即停止；日志形成对应的 `key=a` Down/Up 配对。
- [x] **收尾**：测试完成后通过设置界面恢复个人快捷键，或退出 AFA 后还原备份的 `Settings.ini`。
