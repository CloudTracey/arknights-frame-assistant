## 集成测试

### 实际游戏与混音器

> 涉及模块：HotkeyService、GameAudioController、GameAudioMute。前置：退出桌面完整版，只运行该候选；游戏出声，另一个程序持续播放声音，打开 Windows 音量混合器。

- [x] **操作**：在游戏中按 F3 两次，然后静音后提高音量；再静音后降低音量。
- [x] **预期**：两次 F3 分别静音和恢复；提高音量后出声；降低保持静音。用户于 2026-10-09 反馈第一组全部通过；接口先写音量再解除静音的顺序另由冒烟测试验证。
- [ ] **操作**：将游戏会话设为 50%，每次提高/降低一次，按住连续调节，分别达到 100% 和 0%；0% 时先降低再提高，100% 时先提高再降低。
- [ ] **预期**：每次 10 个百分点；不越界；最终分别是 10% 和 90%；提示与混合器一致，其他程序和系统总音量不变。
- [ ] **操作**：关闭游戏声音产生的会话或退出游戏，再触发快捷键；重新启动游戏并操作。
- [ ] **预期**：无会话时提示未找到，不声称成功；无游戏时原快捷键生效条件维持；重启后只影响新游戏，不操作旧接口。
- [ ] **操作**：开启悬停操作，将游戏置后台且鼠标停在游戏内，使用键盘及滚轮绑定；排队按键后立即切换窗口。
- [ ] **预期**：按原有触发条件生效，不强制激活游戏，不改变其他程序声音；只处理按下时选定的游戏窗口。

### 异常与设备

- [ ] **操作**：依次使用 Realtek、iKF 和显示器输出；每次切换后重新触发静音及音量键，断开当前设备再重连。
- [ ] **预期**：可用的新会话响应按键；某设备不可用时其他会话继续处理，失败有提示。自动保持切换前意图属于后续 PR，本项不据此判通过。
