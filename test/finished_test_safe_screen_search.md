# 测试清单：`safe_screen_search`

> 对应更改：为 `PixelSearch`/`ImageSearch` 增加安全包装 `SafePixelSearch`/`SafeImageSearch`（`base/window.ahk`）——搜索矩形整体在可见桌面之外时先行跳过（越界前置校验，镜像 AHK CoordToScreen 的坐标基准），其余 GDI 失败（OSError，典型"句柄无效"）一律按"未命中"处理并节流记录日志，不再抛未处理异常弹错误框。`LevelDetector` 的 3 对象颜色检测与 `GameMonitor` 的黑屏/三条扫描线/暂停键/代理接管识别共 8 处调用点全部改走包装；`GameMonitor` 的三段搜索区补 `try/finally` 保证 DPI 感知上下文必然恢复（原实现搜索抛异常会跳过恢复，之后该线程持续以 per-monitor aware 运行）。

- [x] **异常**：游戏窗口最小化（游戏前台状态按 Win+M 或任务栏最小化）→ **预期**：无错误弹窗（越界前置校验/OSError 兜底，日志最多出现节流 WARN）；窗口复原后识别自愈
