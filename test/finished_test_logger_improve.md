## 问题反馈

### 问题1：启动时点击控制台提示弹窗「确定」报错 "String has no property named Hwnd"
- **现象**：勾选调试模式后重启，启动早期弹出控制台提示窗，点击「确定」崩溃。
- **根因**：key_bind.ahk 进程级 WM_LBUTTONDOWN 处理器（:332）假设 `GuiManager.MainGui` 已初始化，启动早期 GUI 尚未创建时 MainGui 为空字符串，`.Hwnd` 抛错。控制台提示/崩溃通知等早期弹窗暴露了此潜在缺陷。
- **修复**：处理器两处访问 `GuiManager.MainGui.Hwnd` 前加 `MainGui != ""` 防御（:272 语义修正 + :332 崩溃修复）。
- [x] 已解决

### 问题2：控制台弹出但无内容显示
- **现象**：控制台窗口正常打开，但无任何日志内容。
- **根因**：原方案 `FileOpen("CONOUT$")` + `WriteLine` 使用 AHK File 内部缓冲（File.htm：「File objects internally buffer reads or writes」），控制台不关闭不刷新，写入永不落盘。
- **修复**：改用 `WriteConsoleW` 直接写入（无缓冲、UTF-16 原生、实时渲染），移除 FileOpen 路径；同步更新计划文档与实现。
- [x] 已解决

### 问题3：黑屏识别日志过于频繁
- **现象**：游戏正常非黑屏时，每轮轮询都输出「黑屏检测失败」日志，刷屏。
- **修复**：移除 `missCount > 3` 分支的高频 Debug，仅保留"检测到开局黑屏"正向提示。
- [x] 已解决

### 问题4：点击控制台窗口内导致 AFA 卡死
- **现象**：左键点击控制台内部，AFA 整体卡死，按回车才恢复。
- **根因**：Windows 控制台默认开启 **QuickEdit 选择模式**，点击/框选控制台会进入选择态，阻塞进程的控制台 I/O（`WriteConsoleW` 被阻塞）。
- **修复**：`SetConsoleEnabled` 中经 `GetConsoleMode`/`SetConsoleMode` 清除 `ENABLE_QUICK_EDIT_MODE(0x0040)` 并置位 `ENABLE_EXTENDED_FLAGS(0x0080)`。
- [x] 已解决

### 问题5：识别到 Loading 后仍弹出黑屏识别超时
- **现象**：黑屏识别到 Loading（红/蓝/白任一）后，8 秒超时提示仍触发。
- **根因**：新增 `StopSearchLoadingTimeout` 定时器后，解除定时的三处仍写 `SetTimer StopSearchLoading, 0`，未解除新定时器。
- **修复**：三处解除定时改为 `SetTimer StopSearchLoadingTimeout, 0`。
- [x] 已解决
