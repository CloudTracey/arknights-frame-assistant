## 单元测试

### 配色与编辑器

- [x] **操作**：打开“其他 → 显示”，选择“自定义主题”并打开编辑器。
  - [x] **预期**：其他三种模式保留；编辑器提供窗口背景、控件背景、主要文字和强调色，初始为深色配色。主窗口布局无重叠。
- [x] **操作**：分别使用颜色选择器和 HEX 输入修改四种颜色。
  - [x] **预期**：完整合法色值即时预览；不完整／非法值提示且不接受完成编辑。取色器取消不改变颜色。
- [x] **操作**：设置低对比度颜色，然后恢复浅色／深色配色。
  - [x] **预期**：低对比度提示不阻止保存；编辑器本身保持可读。恢复配色不清除背景图片。
- [x] **操作**：编辑后点击“完成编辑”，再次打开编辑器调整，然后取消。
  - [x] **预期**：完成编辑只修改主窗口工作副本并标为未保存；编辑器取消恢复本次打开前方案，不抹掉上一次已接受的工作副本。

### 背景与控件

- [x] **操作**：选择 PNG、透明 PNG、JPG/JPEG、BMP，分别切换填满裁切与完整显示。
  - [x] **预期**：保持纵横比、居中裁切或留白；透明区与留白使用窗口背景色。
- [x] **操作**：调节图片不透明度至 0%、20%、100%，然后移除图片。
  - [x] **预期**：只改变图片强度，不让整个窗口透明；0% 或移除时恢复纯色。
- [x] **操作**：检查文字、复选框、分组、状态栏、顶部标签和拖拽高亮；操作输入框、下拉框和按钮。
  - [x] **预期**：背景连续，无文字底色矩形或错位；输入区域、按钮、选中行保留实色，焦点、选区与输入正常。
- [x] **操作**：将图片或背景颜色设置为包含 `#FFA8A8`，移动窗口到其他窗口上。
  - [x] **预期**：没有颜色键透明洞或点击穿透。
