## 单元测试

### 功能点：快捷键绑定

- [x] **操作**：打开“其他设置 → 自定义”。**预期**：显示“切换常规/卫戍方案”输入框，首次安装时为空；悬停可看到切换用途。
- [x] **操作**：点击该输入框，录入一个未占用的键并点击“应用设置”，关闭设置窗口后再打开。**预期**：绑定值仍在，保存/应用按钮恢复未修改状态。
- [x] **操作**：对该输入框按 Backspace 或 Delete，应用后重新打开。**预期**：绑定为空，原键不再切换方案。
- [x] **操作**：将切换键绑定为现有常规、卫戍、音量或“启用/禁用热键”键之一。**预期**：冲突输入框标红，保存与应用不可用；解除冲突后恢复。

## 集成测试

### 流程：双向切换

> 涉及模块：热键 schema、HotkeyService、GuiManager、配置文件。

- [x] **前置**：给切换键绑定一个未占用的键；给常规和卫戍各绑定一个容易观察效果的键；应用设置，使游戏窗口处于前台。
- [x] **操作**：在常规方案中按一次切换键。**预期**：出现“已启用卫戍协议方案”提示；卫戍键生效、常规键停用；重新打开设置时卫戍标签和勾选状态一致。
- [x] **操作**：再次按切换键。**预期**：出现“已退出卫戍协议方案”提示；常规键恢复、卫戍键停用；重新打开设置时常规标签和勾选状态一致。
- [x] **操作**：按住切换键超过一秒再松开。**预期**：每次按住只切换一次；松开后再次按下可再切换。
- [x] **操作**：先进入“其他设置”或“自定义按键”页，关闭设置窗口，再按切换键。**预期**：方案切换成功，重新打开设置时显示切换后的功能页。
- [x] **操作**：关闭“启用/禁用热键”总开关后按方案切换键，再重新开启总开关。**预期**：关闭期间方案不变；重新开启后切换键仍可用。
- [x] **操作**：将“默认启动卫戍协议方案”设为启用并应用，重启 AFA。**预期**：启动后初始方案为卫戍协议；再按保存的方案切换键，绑定继续有效并切换到常规方案。

##### 异常路径

- [x] **异常**：游戏未运行或游戏窗口不在可触发范围时按切换键。**预期**：方案不变，也不影响其他窗口的输入。
- [x] **异常**：隐藏卫戍协议标签后按切换键，先按预先绑定的卫戍专用键或检查活动模式指示器，再点击当前可见的常规功能标签。**预期**：切换后先确认卫戍热键组已生效；点击常规标签后回到常规方案，勾叉与实际生效按键一致。
