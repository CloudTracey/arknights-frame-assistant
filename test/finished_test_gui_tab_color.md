## 问题反馈

### 问题1：指示线偶发右移到「卫戍协议」和「自定义按键」之间，且比标签长

- 具体现象：在卫戍协议页/方案切换后，顶部蓝线右移约 1/6 屏宽并变长（截图像素实测宽约 139 逻辑像素，正常为 120）。
- 原因：指示线位置与宽度来自标签控件的 `GetPos()`；系统 DPI 150% 与显示器 175% 不一致时 `GetPos` 与 `Move` 缩放基准不同，坐标被二次放大 7/6。
- 修复：指示线位置/宽度改为 `GuiWidth / 可见标签数` 的等分布局计算，不再使用 `GetPos`。
- [x] 已解决（追加测试全部通过：往返切换、隐藏/恢复标签、跨缩放显示器、深色主题）

### 问题2：切换界面语言时日志出现 `The control is destroyed.` ERROR

- 具体现象：2026-11-17 22:13:47 切换 zh-Hans → ko-KR 时，`[EventBus] 事件回调异常：event=ForegroundClientChanged ... error=The control is destroyed.`。
- 原因：`Rebuild()` 销毁旧窗口后，`ServerPathsText`/`RunningClientsText` 仍指向旧控件；`GameMonitor` 的前台客户端事件在 `Init()` 重建控件前到达，刷新函数写入已销毁控件。
- 修复：`Rebuild()` 在销毁旧窗口前置空这两个控件引用，事件中途到达时刷新函数跳过写入；新控件创建时按当前数据重新生成文本。
- [x] 已解决（追加测试通过：连续 4 次语言切换日志 0 ERROR、0 个 `control is destroyed`，客户端文本正常刷新）
