## 问题反馈

### 问题1：Change C 初版关卡检测失效（改后 2.4 不通过，无法正常检测关卡）
- 现象：进关卡后守卫不触发（InLevel 判定失败），关卡检测失效
- 原因：`SafeCaptureClientRect` 初版用 `GetDC(窗口)` 捕获——DX/Unity 游戏画面不经过窗口 GDI DC，捕获结果为黑屏/旧帧，内存扫描全 miss
- 修复：改为**屏幕 DC**（GetDC(NULL) + ClientToScreen 客户区原点偏移 + BitBlt），与 PixelSearch 的屏幕合成路径语义一致；本机探针（450×300、像素 B=0 G=0 R=255、字节序正确）已验证
- [x] 已解决（重建后 2.4/2.4b 复测通过；2.4b：进关卡识别成功、退出关卡后约 333ms 内恢复拦截）
