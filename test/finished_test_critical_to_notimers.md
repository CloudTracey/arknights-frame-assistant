# 测试清单：`critical_to_notimers`

> 对应更改：将暂停选中/一键技能/一键撤退/暂停技能/暂停撤退/视角切换的 `Critical` 保护改为 `Thread "NoTimers"`——仍挡定时器轮询的时序干扰，但允许其他热键中断动作（如一键技能期间切倍速即时响应）；过帧三件套（16/33/166ms）保留 `Critical`

## 集成测试

### 流程 1：一键技能执行期间切倍速（核心诉求）

> 涉及模块：`hotkey_actions`、`game_keys`、`level_detector`

- [x] **前置**：进入任意关卡，守卫开启（InLevelGuard=1），已绑定「一键技能」「切换倍速」热键
- [x] **操作**：按「一键技能」热键，在其动作执行期间（约 0.2s）立即按「切换倍速」
- [x] **预期**：倍速立即切换（游戏倍速图标变化），无需等待一键技能动作结束
- [x] **预期**：一键技能仍正常释放（技能成功触发，未因中断而丢失）
- [x] **操作**：重复上述操作 5~10 次，混合不同时机
- [x] **预期**：每次倍速都即时响应，无偶发丢失；一键技能稳定生效

### 流程 2：暂停技能/暂停撤退期间热键响应

> 涉及模块：`hotkey_actions`、`touch_injection`、`game_keys`

- [x] **前置**：进入关卡，绑定「暂停技能」「暂停撤退」热键
- [x] **操作**：对一名干员使用「暂停技能」，动作期间立即按「切换倍速」
- [x] **预期**：倍速立即响应；暂停技能完整执行（干员技能被选中并释放）
- [x] **操作**：对一名干员使用「暂停撤退」，动作期间立即按其他热键（如倍速）
- [x] **预期**：其他热键立即响应；暂停撤退完整执行

### 流程 3：视角切换/暂停选中期间热键响应

> 涉及模块：`hotkey_actions`、`touch_injection`

- [x] **前置**：进入关卡，绑定「视角切换」「暂停选中」热键
- [x] **操作**：使用「视角切换」，动作期间立即按其他热键
- [x] **预期**：其他热键立即响应；视角切换完整执行（完成后视角回到暂停按钮位置）
- [x] **操作**：使用「暂停选中」选择一名干员，动作期间立即按其他热键
- [x] **预期**：其他热键立即响应；干员被选中（选中框出现）

### 流程 4：NoTimers 仍挡定时器轮询（原保护不失效）

> 涉及模块：`hotkey_actions`、`level_detector`、`logger`

- [x] **前置**：打开 AFA 调试控制台（或 DebugView），启用 DEBUG 日志
- [x] **操作**：在关卡内反复使用「暂停选中」「一键技能」「暂停技能」等动作
- [x] **预期**：日志中不出现（或极少出现）`USleep 超时` 诊断（overshoot ≥1ms）——NoTimers 期间 LevelDetector 轮询不再插入 USleep
- [x] **预期**：动作整体时序稳定，无明显的单次过帧波动

### 流程 5：过帧三件套保留 Critical（帧数精确性不受影响）

> 涉及模块：`hotkey_actions`

- [x] **前置**：进入关卡，绑定 16ms/33ms/166ms 过帧热键
- [x] **操作**：使用「过帧 33ms」，在过帧动作执行期间立即按其他热键
- [x] **预期**：过帧动作不被中断（其他热键被缓冲），帧数精确前进 1 帧，无跳帧/漏帧
- [x] **操作**：反复使用 16/33/166ms 过帧各 10 次
- [x] **预期**：帧数前进稳定，无一次过两帧或不过帧

##### 异常路径

- [x] **异常**：暂停技能动作期间（SendDown 与 SendUp 之间）插入另一热键 → **预期**：中断结束后动作继续完成，技能键松开状态正常，无卡键
- [x] **异常**：动作执行期间极速连按多个热键 → **预期**：热键逐个响应，无卡键、无异常弹窗
- [x] **异常**：动作执行期间点击游戏窗口外（鼠标悬停判定） → **预期**：热键不误触发（窗口外判定行为不变）
