## 单元测试

### 功能点：默认状态与提示样式

- [x] **操作**：打开设置窗口，进入“常规作战”或“快捷操作”页面。
- [x] **预期**：默认没有冲突输入框标红，底部冲突提示隐藏，保存和应用按钮保持原有状态。
- [x] **操作**：将“前进 16ms”绑定为 `R`，将“前进 33ms”也绑定为 `R`。
- [x] **预期**：两个输入框立即标红，底部显示“存在按键冲突”，保存和应用按钮立即禁用。

### 功能点：冲突解除

- [x] **操作**：将其中一个重复按键改为其他未占用按键。
- [x] **预期**：冲突双方立即恢复正常颜色，冲突提示消失；若仍有其他未保存修改，保存和应用按钮恢复可用。
- [x] **操作**：使用 `BACKSPACE` 或 `DELETE` 清除其中一个冲突按键。
- [x] **预期**：冲突立即解除，空按键不参与冲突检测。

### 功能点：不同冲突分组

- [x] **操作**：将常规作战按键与快捷操作按键设置为同一个按键。
- [x] **预期**：两个输入框立即标红。
- [x] **操作**：将卫戍协议按键设置为与常规作战按键相同的按键。
- [x] **预期**：不提示冲突，因为两组按键不会同时启用。
- [x] **操作**：将“启用/禁用热键快捷键”设置为常规作战或卫戍协议中的已使用按键。
- [x] **预期**：相关两个输入框立即标红。

### 功能点：多方重复与修复

- [x] **操作**：让三个按键功能使用同一个按键。
- [x] **预期**：三个相关输入框全部标红，而不是只标红最后两个。
- [x] **操作**：逐一修改重复按键，直到只剩一个功能使用该按键。
- [x] **预期**：所有红色状态和冲突提示正确清除。

## 集成测试

### 流程：按键录制与设置保存

> 涉及模块：`key_bind.ahk`、`gui.ahk`、`settings/hotkey_conflict_validator.ahk`、`settings/saver.ahk`

- [x] **前置**：设置窗口已打开，工作区没有其他正在录制的按键。
- [x] **操作**：修改两个同组按键为相同的键盘键。
- [x] **预期**：录制结束后立即显示冲突样式，不需要点击保存或切换页面。
- [x] **操作**：尝试点击“保存并关闭”和“应用设置”。
- [x] **预期**：按钮不可点击，配置文件不被写入。
- [x] **操作**：修复冲突后点击“应用设置”。
- [x] **预期**：设置成功应用，冲突样式清除，热键可以正常重新注册。

### 流程：取消、重置和重新打开

> 涉及模块：`settings/actions.ahk`、`settings/loader.ahk`、`gui.ahk`

- [x] **前置**：制造一个实时冲突。
- [x] **操作**：点击“取消”，再次打开设置窗口。
- [x] **预期**：输入框恢复已保存值，冲突标红和提示清除。
- [x] **操作**：制造冲突后点击“重置按键”。
- [x] **预期**：默认按键重新加载，所有冲突状态清除。
- [x] **操作**：关闭设置窗口后重新打开。
- [x] **预期**：界面样式与当前内存/配置状态一致。

##### 异常路径

- [x] **异常**：从旧配置加载已经存在重复按键的配置 → **预期**：打开设置窗口后立即标红并禁止保存，允许用户修复后保存。
- [x] **异常**：切换到包含冲突控件的其他标签页 → **预期**：切换后红色样式仍存在。
- [x] **异常**：按键录制过程中点击其他输入框或失去设置窗口焦点 → **预期**：录制取消，不产生新的冲突状态。
