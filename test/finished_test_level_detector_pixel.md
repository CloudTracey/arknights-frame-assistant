# 测试清单：`level_detector_pixel`

> 对应更改：关卡检测改为 **PixelSearch 颜色检测投票状态机**——每秒轮询对 3 个关卡内专属对象（关卡内文本 `TextInLevel`/退出按钮 `ExitButton`/暂停按钮 `PauseButton`）做颜色检测，命中 ≥2 个置位 `State.InLevel`、<2 复位。区域用相对比例定位（`LX/RX/UY/DY` = ww/wh 比例），不依赖模板尺寸（分辨率/UI 缩放鲁棒）。低分辨率（长或宽任一 <1600×900）时 `TextInLevel` 容差放宽到 20。`GuardInLevel` 读 `State.InLevel`。对象颜色：TextInLevel 白 V1、ExitButton 灰/深红/黄绿 V3、PauseButton 白/浅灰 V3。
