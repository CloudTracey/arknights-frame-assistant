# 测试清单：顶部标签页可见性与顺序

## 测试环境

| 项目 | 信息 |
|------|------|
| AFA 版本 | 当前工作区版本 |
| AutoHotkey 版本 | v2.0.26 |
| Windows 版本 | Windows 11 25H2 |
| 测试日期 | 2026-07-30 |

## 测试步骤

### 测试 1：默认状态与固定标签

- [x] 步骤 1：使用全新配置启动 AFA。
- [x] 步骤 2：打开“其他设置 → 自定义”。
- [x] 验证：“顶部标签页”列表按“常规作战、快捷操作、卫戍协议、其他设置”的顺序显示。
- [x] 验证：四个标签的眼睛均为显示状态，顶部栏显示四个等宽标签。
- [x] 步骤 3：点击“其他设置”的眼睛图标。
- [x] 验证：“其他设置”仍保持显示，列表中标记为固定。

### 测试 2：切换可见性

- [x] 步骤 1：点击“卫戍协议”的眼睛图标将其隐藏。
- [x] 验证：管理列表中的眼睛立即切换为隐藏状态，但顶部栏、勾叉和模式切换提示保持上次保存或应用的状态。
- [x] 步骤 2：点击“应用设置”。
- [x] 验证：顶部按“常规作战、快捷操作、其他设置”的顺序显示三个等宽标签，“卫戍协议”入口不可见。
- [x] 验证：常规作战和快捷操作标签名称后不显示勾叉，页面不显示卫戍协议按键禁用提示。
- [x] 步骤 3：再次点击“卫戍协议”的眼睛图标。
- [x] 验证：应用前顶部栏保持隐藏；应用后卫戍协议标签、勾叉状态、模式切换提示和四等分布局恢复。
- [x] 步骤 4：分别隐藏“常规作战”和“快捷操作”并应用设置。
- [x] 验证：顶部只显示“卫戍协议”和“其他设置”，且两个标签各占一半宽度。

### 测试 3：拖拽排序

- [x] 步骤 1：将“其他设置”拖到列表首位，将“卫戍协议”拖到第二位。
- [x] 验证：管理列表立即按新顺序排列，但顶部栏仍保持上次保存或应用的顺序。
- [x] 步骤 2：点击“应用设置”。
- [x] 验证：顶部栏按新顺序排列，所有可见标签仍等宽。
- [x] 步骤 3：隐藏其中一个标签后继续拖拽其他标签。
- [x] 验证：隐藏项仍保留在管理列表中，顶部栏的顺序和可见性都保持上次应用结果。

### 测试 4：当前页与按键方案回退

- [x] 步骤 1：先进入“卫戍协议”，再打开“其他设置 → 自定义”并隐藏“卫戍协议”。
- [x] 验证：应用前仍保持卫戍协议按键方案，顶部勾叉和冲突提示不变。
- [x] 步骤 2：点击“应用设置”。
- [x] 验证：按键方案切换到已应用顺序中最靠前的可见功能标签，勾叉和冲突提示同时隐藏。
- [x] 步骤 3：隐藏当前按键方案对应的功能标签并应用设置。
- [x] 验证：按键方案切换到已应用顺序中最靠前的可见功能标签。
- [x] 步骤 4：隐藏“卫戍协议”但暂不应用。
- [x] 验证：“默认启动卫戍协议方案”选项仍可操作；应用后变为不可操作，重新显示并应用后恢复。

### 测试 5：保存与取消

- [x] 步骤 1：调整标签顺序和可见性，点击“应用设置”或“保存并关闭”，然后重启 AFA。
- [x] 验证：标签顺序和可见性保持不变。
- [x] 步骤 2：再次修改标签顺序和可见性，点击“取消”。
- [x] 验证：列表、顶部栏、提示和按键方案均恢复到上次保存的状态。

### 测试 6：异常配置容错

- [x] 步骤 1：在 `TabOrder` 中加入未知项、重复项并遗漏一个已知标签，随后重启 AFA。
- [x] 验证：未知项和重复项被忽略，遗漏的已知标签自动追加，程序正常启动。
- [x] 步骤 2：在 `HiddenTabs` 中加入 `other` 和未知项，随后重启 AFA。
- [x] 验证：“其他设置”仍可见，未知项不影响界面。
