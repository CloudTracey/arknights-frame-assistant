## 集成测试

### 流程：正常识别 → 保存 → 启动游戏

> 涉及模块：`game_launcher`、`gui`、`saver`

- [x] **前置**：明日方舟已运行
- [x] **操作**：点击"识别游戏路径"，确认路径填入正确 → 点击"保存并应用"
- [x] **预期**：保存成功，无警告弹窗。AFA 日志中无 "降级到 WMI" 字样（说明 `ProcessGetPath` 正常工作）

### 流程：WMI 降级路径验证（日志审查）

> 涉及模块：`game_launcher`、`logger`

- [x] **前置**：打开 AFA 日志目录（`%AppData%\ArknightsFrameAssistant\PC\logs\`）
- [x] **操作**：搜索日志中是否存在 `ProcessGetPath 异常` 或 `降级到 WMI 查询` 字样
- [x] **预期**：正常环境下无此日志（`ProcessGetPath` 未被拦截）

##### 异常路径

- [ ] **异常**：`ProcessGetPath` 被安全软件拦截（需在拦截环境中测试）→ **预期**：日志出现 `ProcessGetPath 失败，降级到 WMI 查询`，随后 `WMI 降级查询成功: <路径>`，路径正确填入编辑框
- [ ] **异常**：WMI 服务不可用（罕见）→ **预期**：日志出现 `WMI 降级查询也失败`，弹出警告窗"未检测到游戏进程，请先启动游戏再进行识别"
