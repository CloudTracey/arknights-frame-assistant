# 测试清单：`test_web_engine_host`

> 对应更改：新增可选 web 引擎（`UiEngine=web`）的 WebView2 宿主 —— 预检 Runtime、资源完整性及控制器创建超时；通过后创建承载窗口并加载 `app/index.html`。若 Runtime 缺失、资源目录不存在、控制器创建超时、虚拟源映射失败或导航异常，一律回退至经典界面，记录 Warn 日志并触发一次性托盘气泡提示。

- [x] **异常**：`app` 资源目录缺失 → **预期**：回退经典界面 + Warn + 一次气泡，AFA 功能不受影响
