## 集成测试

### 流程：快捷操作"返回上级菜单"——勾选时补发放弃行动

> 涉及模块：`hotkey_actions`、`game_keys`、`config`、`gui`

- [x] **前置**：游戏运行中；设置中勾选"使用"返回上级菜单"放弃行动"并应用；"返回上级菜单"（Back）已绑定一个热键
- [x] **操作**：在游戏主界面或任意上级菜单界面，按下"返回上级菜单"热键
- [x] **预期**：先发送 ESC（返回上级菜单），随后触发"放弃行动"，与旧版"放弃行动"行为一致

### 流程：快捷操作"返回上级菜单"——未勾选时仅返回

- [x] **前置**：取消勾选"使用"返回上级菜单"放弃行动"并应用；Back 已绑定热键
- [x] **操作**：按"返回上级菜单"热键
- [x] **预期**：仅发送 ESC 返回上级菜单，不触发"放弃行动"弹层

##### 异常路径

- [x] **异常**：勾选了"使用"返回上级菜单"放弃行动"，但"返回上级菜单"未绑定任何热键 → **预期**：checkbox 本身不报错，设置可正常保存；未绑定时该功能不触发，无异常

### 流程：关卡守卫开关——关闭后常规作战热键全场可用

> 涉及模块：`level_detector`、`hotkey_actions`、`loader`、`settings`

- [x] **前置**：取消勾选"在非战斗关卡场景禁用常规战斗热键"，点击"应用设置"
- [x] **操作**：在游戏主界面（非战斗）按"按下暂停"热键（默认 f）
- [x] **预期**：热键直接生效（发送 ESC，产生可见反应），不再被关卡检测拦截
- [x] **操作**：（可选）用 DebugView 观察 OutputDebug 日志，同样在主界面按"按下暂停"
- [x] **预期**：不出现 `被关卡检测拦截（不在关卡界面）` 的 Info 日志（说明已停止关卡状态轮询）
- [x] **操作**：进入任意战斗关卡，按"按下暂停"或"单位技能"热键
- [x] **预期**：热键仍然生效

### 流程：关卡守卫开关——重新开启后恢复拦截

- [x] **前置**：重新勾选"在非战斗关卡场景禁用常规战斗热键"，点击"应用设置"
- [x] **操作**：在游戏主界面（非战斗）按"按下暂停"热键（默认 f）
- [x] **预期**：恢复拦截——按键被吞并透传原键（主界面 f 无游戏功能，通常无可见反应）
- [x] **操作**：DebugView 观察日志，再次按"按下暂停"
- [x] **预期**：出现 `被关卡检测拦截（不在关卡界面）` 的 Info 日志
- [x] **操作**：进入战斗关卡后按常规作战热键
- [x] **预期**：恢复生效
- [x] **操作**：DebugView 观察关卡检测恢复
- [x] **预期**：关卡状态切换时出现 `关卡状态切换：进入/退出关卡` 日志（轮询已恢复）

### 流程：启动时遵循已保存的守卫开关

- [x] **前置**：`InLevelGuard=0` 已保存（上一流程结果）
- [x] **操作**：完全退出 AFA 并重新启动，打开游戏，在非战斗界面按"按下暂停"热键
- [x] **预期**：热键直接生效（启动时即未轮询，符合已保存配置）
- [x] **操作**：进入战斗关卡按常规作战热键
- [x] **预期**：生效

##### 异常路径

- [x] **异常**：`InLevelGuard=0` 时游戏未运行 → **预期**：AFA 正常启动运行，无关卡轮询、无报错；启动游戏后常规作战热键正常
