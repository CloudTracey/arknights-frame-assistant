# 测试清单：`switch_tab_no_discard`

> 对应更改：去掉标签页切换时的"修改尚未保存"确认弹窗，修改不再在切换标签页时丢弃，直到用户取消/保存/应用；Config.GetHotkey/GetCustom/GetImportant 改为读内存工作副本，热键注册和运行时逻辑通过新增的 Read*FromIni 方法读取 INI 值；TrackChange 同步控件值到 Config 内存

## 集成测试

### 流程：修改 → 切换标签页 → 保存

> 涉及模块：`gui`、`config`、`settings/saver`、`settings/loader`、`hotkey_control`

- [x] **前置**：游戏未启动（或已启动但不影响测试）
- [x] **操作**：在"常规作战"页修改"按下暂停"为 `H`，切换到"快捷操作"页，点击"保存并关闭"
- [x] **预期**：提示"设置已保存！"，窗口关闭。重新打开设置，切换到"常规作战"页，"按下暂停"显示为 `H`，热键实际生效（游戏中按 `H` 触发暂停）

### 流程：修改 → 切换标签页 → 应用

> 涉及模块：`gui`、`config`、`settings/saver`、`settings/loader`、`hotkey_control`

- [x] **前置**：游戏未启动
- [x] **操作**：在"常规作战"页修改"按下暂停"为 `J`，切换到"卫戍协议"页，点击"应用设置"
- [x] **预期**：提示"设置已应用！"，窗口不关闭。切回"常规作战"页，"按下暂停"显示为 `J`，修改状态清除（按钮禁用、提示消失）

### 流程：修改 → 切换标签页 → 取消

> 涉及模块：`gui`、`config`、`settings/actions`

- [x] **前置**：游戏未启动
- [x] **操作**：在"快捷操作"页修改"基建快速收取"为 `K`，切换到"其他设置"页，点击"取消"
- [x] **预期**：窗口关闭。重新打开设置，切换到"快捷操作"页，"基建快速收取"恢复为修改前的值

### 流程：未保存修改不生效于热键注册（切换标签页时）

> 涉及模块：`gui`、`config`、`hotkey_control`

- [x] **前置**：游戏已启动，AFA 热键已启用
- [x] **操作**：在"常规作战"页修改"技能"按键为一个游戏中不冲突的键（如 `Y`），**不保存**，直接切换到"快捷操作"页
- [x] **预期**：在游戏中按原来的"技能"键（默认 `S`），技能仍然触发；按 `Y` 不触发技能（因为修改未保存，热键注册仍使用 INI 中的旧值）

### 流程：保存后修改生效于热键注册

> 涉及模块：`gui`、`config`、`hotkey_control`、`settings/saver`

- [x] **前置**：游戏已启动，AFA 热键已启用
- [x] **操作**：在"常规作战"页修改"技能"按键为 `Y`，点击"应用设置"
- [x] **预期**：在游戏中按 `Y` 触发技能，原来的 `S` 不再触发技能

- [x] **预期**：AFA 彻底退出（进程结束），不受 `ExitOnWindowClose` 设置影响

### 流程：关闭按钮行为受 ExitOnWindowClose 控制
