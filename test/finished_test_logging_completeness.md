## 问题反馈

### 问题1：GameTarget 解绑日志刷屏（400ms 轮询空解绑）
- 现象：游戏不在前台时日志每 ~400ms 一条 `[DEBUG] [GameTarget] 解绑目标窗口 hwnd=0 pid=0 serverId=`
- 原因：`GameClientRegistry._RefreshForeground` 每次前台轮询无条件调用 `Bind`/`Unbind`；Unbind 无条件记录日志
- 修复：`GameTarget.Bind`/`Unbind` 改为幂等——仅真实绑定/解绑（状态变化）时记录日志（src/lib/base/game_target.ahk）
- [x] 已解决（复测通过：不再有逐 400ms 空解绑记录）

### 问题2：热键冲突日志误入关键日志轨
- 现象：改键途中临时相同按键也会记 WARN，进入 critical-*.log
- 修复：冲突检测日志 WARN → INFO（预期内场景不进关键日志轨；保存中止仍由 SettingsService 记 Warn）（src/lib/core/settings/hotkey_conflict_validator.ahk）
- [x] 已解决（复测通过：`[INFO] [Hotkeys]` 仅普通日志轨出现）
