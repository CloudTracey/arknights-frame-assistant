## 集成测试

### 流程：开启后进入关卡自动切二倍速

> 涉及模块：`GameMonitor`、`GameKeys`、`Config`、`SettingsService`

- [x] **前置**：在设置页勾选「开局自动二倍速」并保存；「开局自动暂停」保持关闭；游戏已启动并处于可进入关卡的界面
- [x] **操作**：以**非代理指挥**方式进入一个常规关卡
- [x] **预期**：进入关卡、战斗界面出现后，游戏倍速自动切换到二倍速（画面右上/倍速按钮显示 2 倍速），无需手动按键
- [x] **预期**：日志（`logs/afa-*.log`）出现「开局自动二倍速：已切换倍速」

### 流程：自动二倍速与自动暂停同时开启

> 涉及模块：`GameMonitor`、`GameKeys`

- [x] **前置**：同时勾选「开局自动暂停」与「开局自动二倍速」并保存
- [x] **操作**：以非代理指挥方式进入常规关卡
- [x] **预期**：开局先自动暂停（与既有行为一致），且倍速被切到二倍速；取消暂停后战斗以二倍速进行
- [x] **预期**：日志同时出现「自动暂停：已暂停 / 非代理指挥，保持暂停」与「开局自动二倍速：已切换倍速」

### 流程：代理指挥（Auto Deploy）时不切倍速

> 涉及模块：`GameMonitor`、`GameKeys`

- [x] **前置**：勾选「开局自动二倍速」并保存
- [x] **操作**：以**代理指挥**方式进入关卡
- [x] **预期**：不自动切换倍速（沿用游戏自动节奏，与自动暂停的代理排除策略一致）；日志不出现「已切换倍速」，或出现代理识别相关记录

### 流程：运行时切换热键

> 涉及模块：`HotkeyActions`、`SettingsService`、`EventBus`、`GuiManager`

- [x] **前置**：为「开局自动二倍速开关」绑定一个按键（如 `P`）并保存；游戏在前台
- [x] **操作**：在游戏内按下绑定键
- [x] **预期**：弹出托盘提示「已开启开局自动二倍速」（或「已关闭…」），设置被即时写入 INI 并切换状态
- [x] **操作**：再次按下绑定键
- [x] **预期**：状态在开/关之间切换，托盘提示对应变化
