## 集成测试

### 流程 1：非代理作战进关自动 2x（仅开倍速）

> 涉及模块：`GameMonitor`、`GameKeys`、`LevelDetector`、`Config`

- [x] **前置**：仅勾选"开局自动二倍速"，不勾选"开局自动暂停"
- [x] **操作**：手动进入一个作战关卡
- [x] **预期**：战斗 UI 就绪后自动切到 2x（倍速图标变为 2x）；日志含"非代理作战，切换二倍速"

### 流程 2：代理作战不干预

> 涉及模块：`GameMonitor`（代理识别）、`GameKeys`

- [x] **前置**：勾选"开局自动二倍速"（可同时勾选自动暂停）
- [x] **操作**：以代理指挥进入关卡
- [x] **预期**：不切倍速、保持代理原生节奏；若同时开了自动暂停，暂停后会被取消（日志"代理指挥，取消暂停"），且全程无"切换二倍速"日志

### 流程 3：与自动暂停组合（非代理）

> 涉及模块：`GameMonitor`、`GameKeys`

- [x] **前置**：同时勾选"开局自动暂停"与"开局自动二倍速"
- [x] **操作**：非代理进入关卡
- [x] **预期**：先自动暂停，随后预设 2x；手动恢复战斗后确实以 2x 运行（重点验证暂停态下切倍速生效）

### 流程 4：运行时热键切换联动

> 涉及模块：`HotkeyService`、`HotkeyActions`、`SettingsService`、`GuiManager`

- [x] **前置**：游戏前台，倍速开关当前为关
- [x] **操作**：按 `P` 开启后进非代理关卡，确认自动 2x；退出后按 `P` 关闭再进关
- [x] **预期**：关闭后进关不再自动切倍速；开关状态与 INI、设置页复选框三方一致

##### 异常路径

- [x] **异常**：进关检测链运行期间关闭游戏窗口或切出前台 → **预期**：状态机按 8 秒超时恢复 400ms 轮询，不卡死、不误切倍速
- [x] **异常**：将 Settings.ini 设为只读后按 `P` → **预期**：日志警告"单键设置写入失败"，托盘不误报开启，程序不崩溃
- [x] **异常**：游戏注册表按键缺失（changeSpeed 回退默认 `f`）→ **预期**：仍能以默认键完成倍速切换
