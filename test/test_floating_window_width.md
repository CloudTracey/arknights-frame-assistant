# 测试清单：按键配置悬浮窗

> 对应更改：新增按当前方案显示已绑定按键的置顶悬浮窗，支持左键穿透、右键移动与缩放、位置/尺寸及显示状态记忆和显示页配置。

| 项目 | 信息 |
|------|------|
| AFA 版本 | v2.2.0 |
| AutoHotkey 版本 | v2.0.26（本机运行时文件版本） |

| 测试日期 | 2026-11-04 |

## 单元测试

- [x] **操作**：按住右键将悬浮窗的左边缘或右边缘向内拖到最窄。
- [x] **预期**：中间空白可以继续收紧；最窄时保留两列文字和约 20 逻辑像素间距；功能名和长按键名称不重叠、不截断。

## 集成测试

- [x] **操作**：收窄后正常退出并重启，再显示悬浮窗。
- [x] **预期**：收窄后的宽度保留，不被额外的固定宽度下限撑大。
- [x] **操作**：更改语言，或增加名称更长的自定义按键并应用。
- [x] **预期**：必要时扩宽到新的内容最小宽度，文字完整显示。

## 回归测试

- [x] **操作**：重新放大宽度，隐藏并显示窗口，再按快捷键切换。
- [x] **预期**：按键列仍靠右；显示、隐藏、托盘勾选和左键穿透正常。
- [x] **操作**：打开“其他设置 → 显示”，分别查看简体、繁体、英文、日文和韩文界面。
- [x] **预期**：原显示设置及顶部标签页管理在左栏；右栏独立显示悬浮窗设置和使用说明；文本不重叠、不遮挡底部按钮。

## 方案切换高度测试

- [x] **前置**：常规作战和卫戍协议的已绑定按键数量不同，悬浮窗已显示。
- [x] **操作**：将窗口手动拉高，再从按键多的方案切到按键少的方案，并切回。
- [x] **预期**：每次方案切换都按当前显示行数收紧或增高，不继承前一方案底部的空白。
- [x] **操作**：在常规作战与快捷操作页面间切换。
- [x] **预期**：同属一个方案组，窗口高度不重置。
- [x] **操作**：悬浮窗隐藏或尚未首次打开时切换方案，然后显示。
- [x] **预期**：高度按切换后的方案内容计算；宽度继续沿用现有保存与内容最小宽度逻辑。

## 追加测试：重启恢复位置与显示状态

- [x] **操作**：显示悬浮窗，按住右键将其移到屏幕一侧并调整大小，松开右键；在设置页修改任意设置并应用，再从托盘退出 AFA 并重新启动。
- [x] **预期**：悬浮窗自动显示，位置与尺寸恢复，托盘项打勾；应用设置不会覆盖已保存的位置或误改显示状态。
- [x] **操作**：隐藏悬浮窗后退出并重启，再通过托盘或快捷键显示。
- [x] **预期**：启动后保持隐藏且托盘项不打勾；再次显示时沿用之前的位置与尺寸。
