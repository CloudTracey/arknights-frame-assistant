## 单元测试

### A．主题入口与基本配色

- [x] **A01 操作**：打开“其他设置 → 显示 → 界面主题”，依次选择深色、浅色、深色。
  - [x] **预期**：选项包含跟随系统、浅色、深色；选择后立即预览，无需重启；窗口底色和文字随之切换，无黑底黑字或白底白字。
- [x] **A02 操作**：保持深色，查看全部顶部页面及其他设置的七个分类。
  - [x] **预期**：标题、普通文字、说明、链接、分隔线清晰；没有成片缺字、遮挡或不合理的浅色背景块。
- [x] **A03 操作**：依次悬停、点击按钮，用 Tab 聚焦并按空格触发；查看未修改设置时的禁用保存/应用按钮。
  - [x] **预期**：正常、悬停、按下、聚焦及禁用状态可区分；文字完整，操作只触发一次，禁用按钮不响应。
- [x] **A04 操作**：检查并切换复选框，分别用鼠标与空格操作；查看分组标题。
  - [x] **预期**：勾选状态明显，文字与背景对比清晰；聚焦和禁用表现正常，无文字被方框覆盖。

### B．顶部与左侧导航（重点）

- [x] **B01 操作**：深色下逐个点击顶部标签；切换浅色再重复。
  - [x] **预期**：当前标签文字使用强调色，下方强调线显示在正确位置；线宽匹配标签，没有被点击层或背景遮挡。
- [x] **B02 操作**：进入其他设置，依次点击通用、显示、启动与退出、更新、自定义、日志、关于；浅色和深色各测一轮。
  - [x] **预期**：只有当前分类左侧出现强调色竖线，文字状态与内容页一致；竖线不消失、不停留在旧分类、不重复出现。
- [x] **B03 操作**：进入显示分类，查看“顶部标签页”五行内容。
  - [x] **预期**：每行名称、拖动手柄、眼睛图标完整可见；“其他设置”的不可隐藏提示清晰，不出现空白行背景。
- [x] **B04 操作**：点击允许隐藏的标签眼睛图标，拖动行改变顺序，再取消设置。
  - [x] **预期**：眼睛命中准确，显隐状态和拖动高亮正确；高亮不遮字；取消后恢复原状态，顶部强调线仍与当前布局一致。

### C．输入框、下拉框和滚动条（重点）

- [x] **C01 操作**：在普通输入框中输入、选中、复制和删除文字，切换焦点；查看只读及禁用输入框。
  - [x] **预期**：内容、光标、选区、边框清晰，文字不被边框覆盖；只读内容可复制但不可编辑，禁用状态可辨认。
- [x] **C02 操作**：展开帧率、主题、更新源及按键类型下拉框，用鼠标和上下键/Enter选择，再关闭列表。
  - [x] **预期**：收起框、展开列表及当前选项清晰；箭头完整、选项不缺字；选值正确，关闭后没有残影。
- [x] **C03 操作**：在“启动与退出”查看已识别路径与当前运行客户端；有足够多行时滚动到顶部、底部并选择复制末行。
  - [x] **预期**：滚动条采用正常系统样式，箭头/滑块无错位或裁切；可读到末行，滚动和复制正常。内容不足以滚动时滑块不动是正常情况；没有长内容时长列表场景记为跳过。
- [x] **C04 操作**：操作自定义延迟等数字输入框旁的增减箭头，切换深浅主题后再操作。
  - [x] **预期**：箭头完整、上下区域响应正确，输入值按原规则变化；主题切换不改变数值或范围。

## 集成测试

### D．窗口、保存与双缓冲

- [x] **D01 操作**：深色下打开自定义按键的齿轮编辑窗口，关闭后重开；再用浅色重复。
  - [x] **预期**：编辑窗口标题栏和内容都跟随主题，深色时不再强制白色标题栏；齿轮、保存、取消和输入框显示正常。
- [x] **D02 操作**：修改主题并“应用设置”，关闭设置窗口再打开；退出程序后重新启动。
  - [x] **预期**：已应用主题保持；窗口重开、程序重启后仍正确，没有恢复成旧主题。
- [x] **D03 操作**：先应用浅色，再预览深色，切换页面后点击取消；反向再做一遍。
  - [x] **预期**：切页不结束预览；取消恢复已保存的主题，顶部/左侧强调线及弹出窗口配色一致。
- [x] **D04 操作**：选择“跟随系统”并应用，切换 Windows 的应用颜色模式，然后恢复原系统设置。
  - [x] **预期**：AFA 自动跟随，无需重启；手动指定深色或浅色时不被普通系统颜色切换覆盖。
- [x] **D05 操作**：在深色下快速切换顶部标签和左侧分类，各往返约10次；输入未保存值，切出后返回；隐藏再显示窗口。
  - [x] **预期**：没有明显逐个控件出现的闪烁、持续空白、残影或响应拖延；文字、强调线及输入值保持，窗口显隐正常。异常时记录切换路线，最好附短录屏。
- [x] **D06 操作**：打开可用的公告、更新提示或应用内错误提示；在独立测试条目中输入非法坐标并尝试保存，再取消编辑。
  - [x] **预期**：应用内提示可读、按钮完整，错误文案明显；校验失败不保存非法内容，关闭提示后原窗口仍可操作。当前触发不了的窗口记为跳过。

### E．浅色、兼容性与邻近交互

- [x] **E01 操作**：切回浅色，重复导航、标签管理器、输入框、下拉框和编辑窗口的基本操作。
  - [x] **预期**：浅色没有新增黑块、缺字或错层；顶部和左侧强调线正常，操作与深色一致。
- [x] **E02 操作**：开启 Windows 高对比度主题，查看导航、输入框与提示窗口；结束后恢复原系统设置。
  - [x] **预期**：系统高对比度配色优先，关键文字与控件清晰；退出高对比度后恢复所选主题。环境不允许切换时记为跳过。
- [x] **E03 操作**：分别在100%、150%缩放下检查标题栏、导航线、五行标签管理器、齿轮、滚动条和弹出列表。
  - [x] **预期**：没有裁切、错位或点击区域偏移；需要时关闭并重开程序再检查。
- [x] **E04 操作**：切换简中、繁中、英文、日文、韩文，复查其他设置→显示及编辑按键窗口。

- [x] **E05 操作**：录制一个测试按键后取消；打开编辑窗口检查名称和坐标输入，最后恢复测试前的设置。
  - [x] **预期**：显示修复不影响按键录制、取消和焦点；没有意外修改常用按键，程序可正常退出。
