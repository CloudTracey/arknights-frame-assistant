## 集成测试

### 流程 1：键盘钩子存活护栏（高频按键压测）

> 涉及模块：`main.ahk`(#HotIfTimeout)、`hook_health.ahk`、`hotkey_service.ahk`、`game_monitor.ahk`

- [x] **前置**：明日方舟在普通作战关卡内，AFA 开启自动开局暂停，调试模式开启
- [x] **操作**：在关卡内快速连打移动键（WASD）与绑定热键（至少 30 秒，尽量制造高频输入）
- [x] **预期**：全程热键持续响应，游戏中角色正常移动/放技能，无卡键、无按键失效
- [x] **操作**：持续游玩 30 分钟以上，期间每隔几分钟记录一次日志时间戳
- [x] **预期**：全程无 `[WARN] [HookHealth] 键盘钩子疑似失效`、无 `[WARN] [HookHealth] 物理按下未触发热键`、无 `[WARN] [KeyForward] Up 补发回环`；若出现任一条，记录时间点与前后日志并反馈

##### 异常路径

- [x] **异常**：关卡内按住热键不松手（如按住暂停约 5 秒）再松开，然后继续正常操作 → **预期**：动作正常执行，不出现"按键卡死"，松开后其他热键照常响应

### 流程 2：自动开局暂停（状态机改造）

> 涉及模块：`game_monitor.ahk`、`hotkey_actions.ahk`

- [x] **前置**：启用 AFA 自动开局暂停，进入任意普通作战关卡准备界面
- [x] **操作**：点击开始行动，观察进关过程
- [x] **预期**：约 2 秒后日志出现 `自动暂停：等待倍速按钮`，随后 `自动暂停：已暂停`；两行时间差在 2~8 秒内，游戏在进关后自动暂停
- [x] **操作**：连续进入 3 个不同关卡（至少一个会自动进入代理作战的关卡）
- [x] **预期**：每个关卡均自动暂停，代理关卡出现 `代理指挥，取消暂停` 且游戏继续运行，非代理关卡出现 `非代理指挥，保持暂停` 且游戏保持暂停

##### 异常路径

- [x] **异常**：进关加载过程中立即 Alt+Tab 切出游戏（停留 15 秒以上），期间继续观察日志 → **预期**：日志出现 `自动暂停：游戏已切出前台，放弃本次自动暂停`，切回游戏后键盘热键与鼠标操作一切正常，未出现凭空暂停
- [ ] **异常**：进关加载完成后立即点击退出关卡（切出游戏窗口），等待 15 秒以上 → **预期**：出现 `自动暂停：等待倍速按钮` 后，约 8 秒内出现 `自动暂停：8 秒内未识别到倍速按钮，放弃本次自动暂停`，之后热键恢复正常响应

### 流程 3：失焦悬停激活（SkipActivate 改造）

> 涉及模块：`hotkey_service.ahk`、`hotkey_actions.ahk`

- [x] **前置**：游戏处于普通关卡内，鼠标悬停在游戏窗口上，但**窗口焦点在其他程序**（如点击桌面对话框后），确认「自定义」页的失焦悬停开关已开启
- [x] **操作**：在游戏失焦状态下按一次「一键技能」
- [x] **预期**：AFA 激活游戏窗口、执行技能，重启后日志出现 `[HotkeyActions] ActionOneClickSkill 执行`，游戏内技能触发
- [x] **操作**：游戏保持前台，连续快速按热键数次
- [x] **预期**：全程热键响应无卡顿，每次按键都执行对应动作，无额外延迟

##### 异常路径

- [x] **异常**：游戏窗口最小化，鼠标停在 AFA 设置窗口上按热键 → **预期**：不激活游戏、不执行动作（该场景应被 HotIf 判定拦住），无卡键

## 问题反馈

### 问题1：失焦悬停触发后探针误报「物理按下未触发热键」

- **现象**：失焦悬停触发热键后，回到游戏内再按 r，日志报 `[WARN] [HookHealth] 物理按下未触发热键：key=r`（连续未命中=1，累计=5），但热键实际正常触发。
- **根因**：命中判定用全局回调计数且宽限期仅 800ms。失焦悬停路径从按下到执行隔着 WinActivate/WaitActive(200ms)+动作耗时，超窗即误判；全局计数还会被其他键的回调干扰。
- **修复**：`HookHealth` 改为按键隔离命中判定（NoteFire 传 pureKey）、宽限期 800ms→3000ms、同键回调即时结算、误报日志标注"可忽略"与 5 秒冷却。
- [x] 已解决（修复后复测失焦悬停场景，不再出现该误报，热键全部正常）

### 问题2：正常长按与快速连点触发诊断误报（WARN 轨刷屏）

- **现象**：按住热键超 3 秒弹 `[WARN] [KeyForward] 等待物理松开已 3s`；快速连点 f 时 `[WARN] [KeyForward] Up 补发回环` 几乎每次点击都触发（间隔 110~140ms），两者均进 critical 日志轨。
- **根因**：`PureKeyWait` 分段观测把"正常长按"当异常记 WARN（此热键本就是按下暂停/松开放行语义）；`Up 补发回环` 判定窗口 200ms 远大于正常连击节奏，且未区分按住周期。
- **修复**：长按观测降为 DEBUG；回环判定窗口收窄至 50ms、新增"周期分隔"判定（两次补发之间若有过新按下即视为两个正常周期）、日志降为 DEBUG。
- [x] 已解决（复测快速连点与长按 3 秒，正常操作不再出现该两条 WARN）
