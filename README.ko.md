## 다운로드 및 실행

1. [GitHub Releases 페이지](https://github.com/CloudTracey/arknights-frame-assistant/releases) 또는 [AFA 공식 다운로드 소스(중국 본토 전용)](https://release.arknightsframeassistant.com/latest)에서 최신 버전의 exe 파일을 다운로드합니다
2. 게임과 함께 실행합니다（순서는 무관합니다）, 또는 설정에서 자동 시작 옵션을 켭니다
3. 변경하고 싶은 키와 설정을 사용자 지정합니다
4. **저장 후 닫기** 또는 **설정 적용**을 클릭하면 게임 내에서 적용됩니다

<br>

## 기능

AFA의 설정 창은 **일반 전투**, **빠른 조작**, **위수 프로토콜**, **사용자 지정 키**, **특수 조작**, **기타 설정**의 6개 페이지로 나뉩니다. 각 페이지의 주요 기능과 설정은 다음과 같습니다.

### 프레임 전진과 정밀 조작

**일반 전투** 페이지에서 사용할 수 있는 단축키 기능 및 관련 설정입니다:

| 기능 | 설명 |
|------|------|
| 누를 때 일시정지 | 누르면 일시정지 전환 |
| 뗄 때 일시정지 | 놓으면 일시정지 전환, 에뮬레이터의「클릭」감각 재현 |
| 배속 전환 | 게임 배속 전환(1배/2배) |
| 일시정지 중 선택 | 일시정지 중 선택하고 싶은 유닛을 클릭해 선택 |
| 스킬 | 스킬 키 클릭 |
| 후퇴 | 후퇴 키 클릭 |
| 시점 전환 | 일시정지 중 유닛에 마우스를 올려 클릭하면 카메라 중심이 해당 유닛으로 전환 |
| 16ms 전진 | 일시정지 중 사용하며 게임 시간을 16ms 진행 |
| 33ms 전진 | 일시정지 중 사용하며 게임 시간을 33ms 진행 |
| 166ms 전진 | 일시정지 중 사용하며 게임 시간을 166ms 진행 |
| 원클릭 스킬 | 스킬을 쓰고 싶은 유닛에 마우스를 올려 누르면 자동 선택 후 스킬 발동 |
| 원클릭 후퇴 | 후퇴시키고 싶은 유닛에 마우스를 올려 누르면 자동 선택 후 후퇴 |
| 일시정지 스킬 | 일시정지 중 스킬을 쓰고 싶은 유닛에 마우스를 올려 누르면 자동 선택 후 스킬 발동 |
| 일시정지 후퇴 | 일시정지 중 후퇴시키고 싶은 유닛에 마우스를 올려 누르면 자동 선택 후 후퇴 |
| 게임 내 프레임 레이트 | 게임이 실제로 구동되는 프레임레이트에 맞춰 단계(30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+)를 선택하여 프레임 전진 지연 계산을 정확하게 유지 |
| 스테이지 내에서만 일반 전투 단축키 활성화(실험적) | 스테이지 화면을 인식해 스테이지 밖에서는 일반 전투 단축키를 비활성화하여 오작동 방지 |

- 세 가지「전진」단축키의 실제 대기 시간은 「기타 설정 → 사용자 지정」에서 조정할 수 있으며, 변경 후 단축키 이름과 상태 표시줄 힌트도 함께 업데이트됩니다

### 빠른 조작

| 기능 | 설명 |
|------|------|
| 왼쪽 클릭 시뮬레이션 | 마우스 왼쪽 버튼 누르기 시뮬레이션 |
| 기반 시설 빠른 수확 | 화면 왼쪽 아래 기반 시설 수확 버튼 클릭 |
| 행동 포기 | 현재 전투 포기 |
| 연출·스토리 스킵 | 마우스를 빠르게 이동해 우측 상단 건너뛰기 버튼 클릭 |
| 로그 아이템 회수 | 마우스를 빠르게 이동해 통합전략의 「받기」 버튼 클릭 |
| 상위 메뉴로 돌아가기 | ESC 키를 시뮬레이션해 상위 메뉴로 복귀 |
| 위 메뉴로 돌아가기로 행동 포기 | 「상위 메뉴로 돌아가기」가 ESC와 동시에 「행동 포기」 키를 누르도록 함 |

### 위수 프로토콜 조작

| 기능 | 설명 |
|------|------|
| 적 확인 | 적 정보 보기 |
| 지휘 센터 | 조정 센터(상점) 열기 |
| 동결 | 조정 센터(상점) 동결 |
| 새로고침 | 조정 센터(상점) 새로고침 |
| 준비 완료 | 준비 완료 확인 |
| 왼쪽 클릭 시뮬레이션 | 마우스 왼쪽 버튼 누르기 시뮬레이션 |
| 업그레이드 | 조정 센터(상점) 업그레이드 |
| 판매·파괴 | 오퍼레이터 판매 / 장비 폐기 |
| 유닛 후퇴 | 선택한 유닛 후퇴 |
| 원클릭 후퇴 | 마우스 위치의 유닛 클릭 후 자동 후퇴 |
| 원클릭 판매·파괴 | 마우스 위치의 오퍼레이터/장비 클릭 후 자동 판매/폐기 |
| 원클릭 구매 | 왼쪽 더블 클릭을 시뮬레이션해 조정 센터 상점의 유닛 구매 |
| 상위 메뉴로 돌아가기 | ESC 키를 시뮬레이션해 상위 메뉴로 복귀 |

> **주의:** 위수 프로토콜 플랜은 일반 전투·빠른 조작 플랜과 상호 배타적입니다. 위수 프로토콜 페이지로 전환하면 일반 전투·빠른 조작 단축키가 비활성화되고, 일반 전투 또는 빠른 조작 페이지로 전환하면 위수 프로토콜 단축키가 비활성화됩니다

### 전체 단축키 사용자 지정

모든 단축키 기능은 설정 창에서 다시 바인딩할 수 있으며, 일반 전투의 일부 상용 기능에만 기본 키가 설정되어 있습니다:

**일반 전투 기본 키:**

| 기능 | 기본 키 | 기능 | 기본 키 |
|------|----------|------|----------|
| 누를 때 일시정지 | F | 16ms 전진 | 없음 |
| 뗄 때 일시정지 | Space | 33ms 전진 | R |
| 배속 전환 | D | 166ms 전진 | T |
| 일시정지 중 선택 | W | 원클릭 스킬 | E |
| 스킬 | S | 원클릭 후퇴 | Q |
| 후퇴 | A | 일시정지 스킬 | 마우스 앞으로 버튼 |
| 시점 전환 | 없음 | 일시정지 후퇴 | 마우스 뒤로 버튼 |

- 키보드의 대부분의 키 바인딩을 지원합니다
- 왼쪽 클릭을 제외한 마우스 버튼（휠, 사이드 버튼 포함）을 지원합니다
- `BACKSPACE/DELETE` 로 바인딩을 지울 수 있습니다
- 키 변경 시 충돌을 실시간 감지하여 관련 입력란을 빨간색으로 표시하며, 충돌을 해결한 후에만 저장할 수 있습니다
- 설정 창 하단의 「키 초기화」로 사용자 지정 키를 제외한 모든 키를 기본값으로 되돌릴 수 있습니다

**사용자 지정 키:**

「사용자 지정 키」 페이지에서는 최대 12개의 사용자 지정 키를 추가할 수 있습니다. 키 이름, 유형(전역 / 일반 전투 / 빠른 조작 / 위수 프로토콜), 기능을 설정하고 게임 창을 클릭하여 작업을 실행할 좌표를 지정합니다. 행 끝의 톱니바퀴 아이콘을 클릭하면 언제든 편집하거나 삭제할 수 있습니다. 키 유형에 따라 적용 범위가 결정됩니다:

- 전역 키: 항상 적용
- 일반 전투 유형: 작전 스테이지 안에서만 적용
- 빠른 조작 유형: 위수 프로토콜 플랜이 비활성화일 때 항상 적용
- 위수 프로토콜 유형: 위수 프로토콜 플랜이 활성화일 때만 적용

### 특수 조작

**특수 조작** 페이지에는 시작 단계와 게임 볼륨 관련 기능이 모여 있습니다:

| 기능 | 설명 |
|------|------|
| 시작 시 자동 일시정지 | 스테이지 진입 시 자동으로 일시정지하며, 「시작 시 자동 일시정지 활성화/비활성화」단축키로 언제든 전환할 수 있습니다 |
| 누르고 있기 시작 자동 일시정지 | 스테이지 로딩 중 누르고 있으면 진입 후 자동으로 일시정지합니다(「시작 시 자동 일시정지 활성화」 체크 여부와 무관) |
| 시작 시 자동 배속 | 스테이지 진입 시 자동으로 배속을 전환하며, 「시작 시 자동 배속 활성화/비활성화」단축키로 언제든 전환할 수 있습니다 |
| 볼륨 높이기 | Windows 볼륨 믹서에서 게임 클라이언트 볼륨 높이기 |
| 볼륨 낮추기 | Windows 볼륨 믹서에서 게임 클라이언트 볼륨 낮추기 |
| 음소거 | 게임 클라이언트 음소거 상태 전환 |

> **힌트:** 「특수 조작」 페이지의 단축키는 기본적으로 할당되어 있지 않으며 해당 페이지에서 직접 할당할 수 있습니다. 게임 볼륨 단축키는 모든 기능 페이지에서 적용됩니다

### 기타 설정

| 기능 | 설명 |
|------|------|
| **인터페이스 언어** | Auto(시스템 설정 따르기), 중국어(간체), 중국어(번체), 日本語, 한국어, English (US) 간에 인터페이스 언어 전환 |
| **화면 테마** | 시스템 설정 따르기, 라이트, 다크 간에 화면 테마 전환 |
| **상단 탭 관리** | 「기타 설정 → 표시」에서 눈 아이콘으로 각 탭 표시 여부를 전환하고 드래그로 순서 변경(기능 탭 최소 1개 유지). 「기타 설정」은 항상 유지되며 저장/적용 후 순서와 표시 여부가 함께 적용되고 상단 바는 보이는 탭 수에 따라 자동 분할됩니다 |
| **게임 프로세스 종료 시 AFA도 종료(권장)** | 모든 게임 프로세스가 종료되면 AFA를 자동 종료 |
| **시작 시 설정 창 열기** | AFA 시작 후 설정 창 자동 열기 |
| **설정 창 닫기 시 AFA 종료** | 체크 시 설정 창 우측 상단 ✗ 클릭으로 AFA 바로 종료, 미체크 시 트레이로 숨김(Alt+F4는 항상 AFA 종료) |
| **기본으로 위수 프로토콜 플랜 시작** | AFA 시작 후 「위수 프로토콜」 플랜으로 바로 전환 |
| **AFA 시작 시 명일방주 시작** | AFA 시작 시 지정 경로의 명일방주 자동 실행(먼저 게임 경로 설정 필요) |
| **게임 경로 감지** | 이 PC의 모든 서버 설치 경로를 한 번에 감지. 감지되지 않으면 게임 실행 후 다시 감지 |
| **명일방주 시작 시 AFA 시작** | 모든 서버의 명일방주가 실행될 때 AFA 자동 시작(관리자 권한 예약 작업 필요) |
| **멀티 서버 지원** | CN, Bilibili, 번체 중국어, 일본어, 한국어, 국제 서버 지원: 각 서버의 게임 내 키 설정을 읽어 동적으로 적응하며, 「시작 및 종료」 페이지에는 감지된 서버 경로와 실행 중인 클라이언트가 읽기 전용으로 표시됩니다 |
| **업데이트 채널** | 정식 버전은 안정적이지만 버그가 있을 수 있음; 테스트 버전은 새 기능이 많고 버그도 더 많을 수 있음 |
| **업데이트 소스** | 중국 본토에서는 Tencent Cloud, 그 외 지역은 GitHub 사용을 권장합니다. 기본값은 Tencent Cloud이며 확인 실패 시 다른 소스로 자동 전환됩니다 |
| **자동 업데이트 확인** | AFA 시작 후 업데이트 자동 확인, 「업데이트」 페이지에서 수동 확인 또는 수동 다운로드 가능 |
| **GitHub Token** | GitHub 소스 사용 시 API 할당량 초과 시에만 입력 후 활성화. Token은 현재 사용자 기준 Windows DPAPI로 암호화 저장 |
| **클릭 지연** | 선택부터 【스킬】【후퇴】, 위수 프로토콜 【판매·파괴】 입력까지의 간격(ms)이 너무 짧으면 클릭이 실패할 수 있습니다 |
| **「단축키 활성화/비활성화」 바로가기** | 모든 단축키를 빠르게 켜고 끄는 단축키 설정(입력란 클릭으로 변경, `BACKSPACE/DELETE`로 지우기) |
| **프레임 스킵 1 / 2 / 3** | 세 가지「전진」단축키의 실제 대기 시간(ms) |
| **게임 창이 비활성 상태여도 마우스 호버 조작 허용** | 게임 창이 비활성 상태여도 마우스를 올리면 단축키 발동 |

## 주의사항

### 명일방주 프로세스에만 적용

이 프로그램의 키 기능은 명일방주 프로세스（`Arknights.exe`）에만 적용되며, 게임 외의 작업에는 영향을 주지 않습니다

### 게임 내 키 설정

AFA는 게임 내 키 설정을 자동으로 읽어 동적으로 맞춥니다

자동 읽기에 실패하면 AFA가 안내를 표시하고 기본 키로 폴백합니다. 이 경우 **게임 내 키를 기본값으로 되돌려** 기능이 정상 동작하도록 해 주세요

### 게임 내 프레임레이트

도우미 내 '게임 내 프레임레이트' 옵션은 **30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+** 입니다. 프레임 전진 지연 계산이 정확하도록 게임의 실제 프레임 수와 일치하는 단계를 선택해 주세요

- 화면 주사율이 **120 Hz 이상**이라면: 수직 동기화를 켜고 프레임 옵션을 120 이상으로 선택할 수 있습니다
- 화면 주사율이 **120 Hz 미만**이라면: 수직 동기화를 끄고, 설정이 게임 내 실제 프레임 수와 일치하도록 하십시오; 수직 동기화를 켠다면 모니터 주사율과 일치해야 합니다

### 보안 안내

이 프로그램은 AutoHotkey로 개발되었습니다. 대부분의 MMORPG나 경쟁 온라인 게임의 안티치트 시스템은 AutoHotkey 기반 프로그램에 매우 민감하여 치트 프로그램으로 오인할 수 있으며, 게임 실행을 막거나 계정을 정지시킬 수도 있습니다.

**'게임 프로세스 종료 시 AFA도 종료' 기능을 켜는 것을 강력히 권장합니다**（기본 켜짐）— 이 도구를 끄는 것을 잊어 다른 게임의 안티치트를 유발하지 않도록 하기 위함입니다.

### 설정 화면을 실수로 닫은 경우

'설정 창 닫기 시 AFA 종료'를 켜지 않았다면, 화면 오른쪽 아래 트레이 영역（숨겨진 아이콘 포함）에서 AFA 아이콘을 찾아 우클릭 → **설정 열기** 선택으로 다시 열 수 있습니다. 해당 옵션이 켜져 있다면 X를 클릭하면 프로그램이 종료되므로 AFA를 다시 시작해야 합니다

## 자주 묻는 질문

### Q: 프로그램을 실행해도 반응이 없나요?

A: 다음을 확인해 주세요:
1. 프로그램이 관리자 권한으로 실행 중인지
2. 게임이 실행 중인지
3. 작업 표시줄 오른쪽 트레이 영역에 도우미 아이콘이 있는지（숨겨진 트레이 아이콘 포함）
4. 설정에서 '시작 시 설정 창 열기'가 꺼져 있지 않은지

### Q: 키를 바인딩해도 적용되지 않나요?

A: 다음을 확인해 주세요:
1. AFA가 '게임 키 읽기 실패' 안내를 띄웠는지（있다면 게임 내 키를 기본값으로 복원）
2. 변경 후 설정을 적용하거나 저장했는지
3. 키가 다른 소프트웨어와 충돌하지 않는지
4. 게임 창 안에서 조작하는지

### Q: GitHub Token이란 무엇인가요? 설정이 필요한가요?

A: GitHub Token은 API 요청 할당량을 올리기 위한 것입니다. API 제한 초과 안내가 있을 때만 설정하면 되며, 보통은 사용할 필요가 없습니다.

GitHub Token은 Windows DPAPI로 현재 Windows 사용자 기준으로 암호화 저장되며 더 이상 평문으로 설정 파일에 기록되지 않습니다. 새 버전 첫 실행 시 이전 버전의 평문 Token은 암호화 형식으로 자동 마이그레이션됩니다; 설정 파일을 다른 Windows 사용자나 컴퓨터로 복사하면 보통 Token을 다시 입력해야 합니다.

### Q: 도우미를 완전히 종료하려면?

A: 트레이 아이콘 우클릭 메뉴에서 '종료'를 선택하거나, '시작 및 종료' 설정에서 **설정 창 닫기 시 AFA 종료**를 켠 뒤 설정 창 우측 상단 X를 클릭하면 종료됩니다. **게임 프로세스 종료 시 AFA도 종료**를 켰다면 게임이 종료될 때 AFA도 함께 종료됩니다.

### Q: 문제 보고를 위해 로그를 수집하려면?

A: 설정의 '로그' 페이지에서 **로그 압축 패키지 생성**을 클릭하고, 생성된 ZIP 파일을 Issue 또는 피드백과 함께 제공해 주세요. 로그는 기본적으로 `%AppData%\ArknightsFrameAssistant\PC\logs`에 저장됩니다
