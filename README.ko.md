**명일방주 프레임 조작 도우미**（Arknights Frame Assistant, 약칭 **AFA**）에 오신 것을 환영합니다

명일방주 PC 클라이언트 경험을 개선하기 위한 간단한 도구로, 전체 단축키 사용자 지정, 프레임 전진, 위수 프로토콜 원클릭 조작 등의 기능을 제공합니다

## 다운로드 및 실행

1. [GitHub Releases 페이지](https://github.com/CloudTracey/arknights-frame-assistant/releases)에서 최신 버전의 exe 파일을 다운로드합니다
2. 게임과 함께 실행합니다（순서는 무관합니다）, 또는 설정에서 자동 시작 옵션을 켭니다
3. 변경하고 싶은 키와 설정을 사용자 지정합니다
4. **저장 후 닫기** 또는 **설정 적용**을 클릭하면 게임 내에서 적용됩니다

<br>

## 기능

### 프레임 전진과 정밀 조작

| 기능 | 설명 |
|------|------|
| 원클릭 스킬 | 마우스가 가리키는 유닛의 스킬을 한 번에 발동 |
| 원클릭 후퇴 | 마우스가 가리키는 유닛을 한 번에 후퇴 |
| 일시정지 중 선택 | 일시정지 중 마우스가 가리키는 유닛을 0프레임에 선택 |
| 일시정지 스킬 | 일시정지 중 마우스가 가리키는 유닛의 스킬을 0프레임에 발동 |
| 일시정지 후퇴 | 일시정지 중 마우스가 가리키는 유닛을 0프레임에 후퇴 |

| 33ms 전진 | 1배속에서 1논리 프레임 전진（게임은 1초당 30논리 프레임） |
| 166ms 전진 | 0.2배속에서 1논리 프레임 전진（유닛 또는 배치 대기 구역 선택 시의 1논리 프레임） |

| 시작 시 자동 일시정지 | 활성화하면 전투 시작 시 자동으로 일시정지되어 배치가 편리 |

## 주의사항

### 명일방주 프로세스에만 적용

이 프로그램의 키 기능은 명일방주 프로세스（`Arknights.exe`）에만 적용되며, 게임 외의 작업에는 영향을 주지 않습니다.

### 게임 내 키 설정

AFA는 게임 내 키 설정을 자동으로 읽어 동적으로 맞춥니다

자동 읽기에 실패하면 AFA가 안내를 표시하고 아래 기본 키로 폴백합니다. 이 경우 **게임 내 키를 기본값으로 되돌려** 기능이 정상 동작하도록 해 주세요:

**일반 전투:**
- 전투 내 배속: F
- 스킬 발동: E
- 오퍼레이터 후퇴: Q
- 행동 포기: V
- 일시정지: Space

**위수 프로토콜:**
- 적 확인: W
- 지휘 센터: A
- 동결: S
- 새로고침: D
- 준비 완료: C
- 업그레이드: G
- 판매: X

### 게임 내 프레임레이트

도우미 내 '게임 내 프레임레이트' 옵션은 **30 / 60 / 90 / 120 / 144 / 165 / 180 / 240+** 입니다. 게임의 실제 프레임 수와 일치하는 단계를 선택해야 프레임 전진 지연 계산이 정확합니다.

- 화면 주사율이 **120 Hz 이상**이라면: 수직 동기화를 켜고 프레임 옵션을 120 이상으로 선택할 수 있습니다
- 화면 주사율이 **120 Hz 미만**이라면: 수직 동기화를 끄고, 설정이 게임 내 실제 프레임 수와 일치하도록 하십시오; 수직 동기화를 켠다면 모니터 주사율과 일치해야 합니다

### 보안 안내

이 프로그램은 AutoHotkey로 개발되었습니다. 대부분의 MMORPG나 경쟁 온라인 게임의 안티치트 시스템은 AutoHotkey 기반 프로그램에 매우 민감하여 치트 프로그램으로 오인할 수 있으며, 게임 실행을 막거나 계정을 정지시킬 수도 있습니다.

**'게임 프로세스 종료 시 자동 종료' 기능을 켜는 것을 강력히 권장합니다**（기본 켜짐）— 이 도구를 끄는 것을 잊어 다른 게임의 안티치트를 유발하지 않도록 하기 위함입니다.

'명일방주와 함께 도우미 자동 실행'을 켜면, Windows는 보안 로그의 프로세스 생성 이벤트로 `Arknights.exe`를 식별하고 현재 사용자 SID가 포함된 예약 작업으로 도우미를 시작합니다. 이 기능을 끄면 현재 사용자의 예약 작업은 삭제되지만 Windows의 '프로세스 생성 성공 감사' 설정은 유지되며 보안 로그 기록량이 늘어날 수 있습니다.

두 자동 실행 방향은 동시에 켤 수 있습니다: 도우미가 게임을 실행할 때 도우미가 중복 실행되지 않고, 게임이 도우미를 실행할 때 게임도 중복 실행되지 않습니다.

### 설정 화면을 실수로 닫은 경우

'창 닫기 시 도우미 종료'를 켜지 않았다면, 작업 표시줄 오른쪽 트레이 영역（숨겨진 아이콘 포함）에서 도우미 아이콘을 찾아 우클릭 → **설정 화면 열기** 선택으로 다시 열 수 있습니다. 해당 옵션이 켜져 있다면 X를 클릭하면 프로그램이 종료되므로 AFA를 다시 시작해야 합니다.

## 자주 묻는 질문

### Q: 프로그램을 실행해도 반응이 없나요?

A: 다음을 확인해 주세요:
1. 프로그램이 관리자 권한으로 실행 중인지
2. 게임이 실행 중인지
3. 작업 표시줄 오른쪽 트레이 영역에 도우미 아이콘이 있는지（숨겨진 트레이 아이콘 포함）
4. 설정에서 '시작 시 설정 창 열기'가 꺼져 있지 않은지

### Q: 키를 바인딩해도 적용되지 않나요?

A: 다음을 확인해 주세요:
1. AFA가 '게임 키 읽기 실패' 안내를 띄웠는지（있다면 게임 내 키를 기본값으로 복원）
2. 변경 후 설정을 적용하거나 저장했는지
3. 키가 다른 소프트웨어와 충돌하지 않는지
4. 게임 창 안에서 조작하는지

### Q: GitHub Token이란 무엇인가요? 설정이 필요한가요?

A: GitHub Token은 API 요청 할당량을 올리기 위한 것입니다. API 제한 초과 안내가 있을 때만 설정하면 되며, 보통은 사용할 필요가 없습니다.

GitHub Token은 Windows DPAPI로 현재 Windows 사용자 기준으로 암호화 저장되며 더 이상 평문으로 설정 파일에 기록되지 않습니다. 새 버전 첫 실행 시 이전 버전의 평문 Token은 암호화 형식으로 자동 마이그레이션됩니다; 설정 파일을 다른 Windows 사용자나 컴퓨터로 복사하면 보통 Token을 다시 입력해야 합니다.

### Q: 도우미를 완전히 종료하려면?

A: 트레이 아이콘 우클릭 메뉴에서 '종료'를 선택하거나, '시작 및 종료' 설정에서 **창 닫기 시 도우미 종료**를 켠 뒤 설정 창 우측 상단 X 또는 Alt+F4로 종료하면 됩니다. **게임 프로세스 종료 시 자동 종료**를 켰다면 게임이 종료될 때 AFA도 함께 종료됩니다.

### Q: 문제 보고를 위해 로그를 수집하려면?

A: 설정의 '로그' 페이지에서 **로그 압축 패키지 생성**을 클릭하고, 생성된 ZIP 파일을 Issue 또는 피드백과 함께 제공해 주세요. 로그는 기본적으로 `%AppData%\ArknightsFrameAssistant\PC\logs`에 저장되며, 일반 로그와 주요 오류 컨텍스트는 별도로 순환 저장되어 합계 20 MiB로 제한됩니다; 내보내기 패키지에서는 Token, 사용자 디렉터리 등 민감 정보를 제거합니다.
